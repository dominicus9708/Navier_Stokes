# Constant-shift vorticity source routes to projective defect

Date: 2026-08-14

Status: **DERIVED QUANTITATIVE ROUTING OF THE `Ab` CORE TERM / REMOVES IT AS AN INDEPENDENT ESCAPE CHANNEL**.

The exact mean-trace identity for the quadratic vorticity core is

\[
J=E_\gamma P+Ab,
\]

where

\[
\eta=Az,
\qquad
b=-\frac12\nabla\times(Az).
\]

The trace term `E_gamma P` is already controlled by the second Hermite-chaos source. This note shows that the remaining `Ab` term is controlled by projective vorticity defect.

## 1. Decompose relative to an arbitrary axis

Fix any unit vector `e`.

Let

\[
P_\perp=I-e\otimes e.
\]

Decompose the linear vorticity matrix as

\[
A=e a^T+A_\perp,
\qquad
 a=A^Te,
\qquad
A_\perp=P_\perp A.
\]

The Gaussian vorticity variance and its transverse/projective part are

\[
V_\omega=\|A\|_F^2,
\qquad
V_\perp=\|A_\perp\|_F^2.
\]

Because `eta=Az` is divergence-free,

\[
\operatorname{tr}A=0.
\]

Set

\[
\alpha=e\cdot a=e^TAe.
\]

Then

\[
\alpha
=-\operatorname{tr}(A_\perp),
\]

and therefore

\[
|\alpha|
\le \sqrt2\,\|A_\perp\|_F.
\]

## 2. Extract the exactly line-aligned divergence-free part

Define

\[
a_0=a-\alpha e,
\qquad
A_0=e a_0^T.
\]

Then

\[
a_0\perp e,
\qquad
\operatorname{tr}A_0=0.
\]

Moreover

\[
A=A_0+E,
\qquad
E=A_\perp+\alpha e e^T,
\]

so

\[
\boxed{
\|E\|_F
\lesssim
\|A_\perp\|_F.
}
\]

The field generated by `A0` is perfectly projectively coherent:

\[
\eta_0(z)=e(a_0\cdot z).
\]

Its curl is

\[
c_0:=\nabla\times(A_0z)
=a_0\times e
\]

up to the fixed orientation convention. Since `a0 dot (a0 cross e)=0`,

\[
\boxed{A_0c_0=0.}
\]

Thus the constant-shift mean source vanishes identically for an exactly line-aligned divergence-free first-chaos vorticity field.

## 3. Perturb away from the aligned state

Let

\[
c(A)=\nabla\times(Az).
\]

This map is linear and satisfies

\[
|c(E)|
\le\sqrt2\,\|E\|_F.
\]

Using `A=A0+E`,

\[
Ac(A)
=(A_0+E)(c(A_0)+c(E)).
\]

The core term `A0 c(A0)` vanishes, so

\[
Ac(A)
=A_0c(E)+Ec(A_0)+Ec(E).
\]

Hence

\[
|Ac(A)|
\lesssim
(\|A_0\|_F+\|E\|_F)\|E\|_F.
\]

Since `||A0|| <= ||A||+||E||`,

\[
\boxed{
|Ac(A)|
\lesssim
\|A\|_F\,\|A_\perp\|_F.
}
\]

Because

\[
b=-\frac12c(A),
\]

we obtain

\[
\boxed{
|Ab|
\lesssim
\sqrt{V_\omega V_\perp}.
}
\]

This holds relative to **any fixed unit axis `e`**.

## 4. Combine with the exact mean-trace identity

The second-chaos trace estimate gives

\[

This is the desired routing statement.

A nonzero quadratic-core mean-vorticity source cannot be generated through a third independent mechanism. It must be carried by at least one of:

1. a second-Hermite-chaos vorticity source;
