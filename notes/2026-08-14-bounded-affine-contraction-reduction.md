# Bounded-affine contraction reduction for geometric heat blocks

Date: 2026-08-14

Status: **REDUCTION LEMMA / FULL MATRIX-WEIGHT IMPLEMENTATION STILL TO BE WRITTEN**.

The exact single-block localization argument is already proved for the isotropic pure-heat chain. To use it without mixing affine-linear feedback into the nonlinear Duhamel term, one needs a homogeneous propagator that contains the bounded affine/mean linearized dynamics.

This note shows that an exact closed-form matrix propagator is not strictly necessary for the localization argument. A uniform homogeneous contraction factor below one is enough, and bounded accumulated affine action allows such a factor after choosing a sufficiently separated geometric scale ratio.

## 1. Abstract homogeneous residual evolution

Write the co-moving residual state `h` schematically as

\[
\partial_t h
-
\nu\Delta h
=
\mathcal L_A(t)h,
\]

where `L_A(t)` contains all terms linear in the residual state generated by the Gaussian affine mean, including coordinate deformation, affine strain/rotation, and the corresponding linearized incompressible coupling.

The genuinely residual-residual nonlinear interaction is excluded from `L_A` and placed in the Duhamel source.

On the bounded-affine branch assume the accumulated linear action on a matched block obeys

\[
\boxed{
\int_{t_p}^{t_c}
\|\mathcal L_A(s)\|_{\rm op}\,ds
\le K_A
}
\]

with `K_A` independent of the first-hitting level.

This is the analytic form of the existing bounded accumulated affine-deformation hypothesis. For Calderon--Zygmund pieces generated by the affine mean, their `L2` operator size is proportional to the corresponding affine/vorticity coefficient, so they are included in the same action ledger after the usual localization/tail audit.

## 2. Heat contraction plus bounded linear action

For the pure matched heat step with covariance ratio

\[
\Sigma_c=c\Sigma_p,
\qquad 0<c<1,
\]

the square-root Gaussian variance contracts by

\[
\sqrt{B_c^{\rm heat}}
\le
\sqrt c\sqrt{B_p}.
\]

Variation of constants and Gronwall for the homogeneous linear perturbation give a multiplicative loss no worse than

\[
C_A:=e^{C K_A}
\]

at the level of the relevant localized/co-moving `L2` seminorm.

Thus the desired homogeneous estimate has the form

\[
\boxed{
\sqrt{B_c^{\rm hom}}
\le
C_A\sqrt c\sqrt{B_p}.
}
\]

The exact constant depends on the chosen co-affine Gaussian norm and the bounded-condition comparison constants, but not on `W`.

## 3. Choose the geometric ratio after K_A is fixed

Since `K_A` is fixed on the bounded-affine branch, choose `c` small enough that

\[
\boxed{
\rho_A:=C_A\sqrt c<1.
}
\]

For example it is sufficient to take

\[
c<\frac{1}{4C_A^2},
\]

which gives `rho_A<1/2`.

The precise numerical value is irrelevant. What matters is that a fixed geometric scale ratio exists whose contraction beats every bounded amount of affine-linear amplification.

## 4. Consequence for single-block localization

With the full step written as

\[
h_c
=\mathcal U_A(t_c,t_p)h_p+Q_j,
\]

where `Q_j` now contains only the genuinely nonlinear residual-residual source and any explicitly separated error branch, the variance seminorm obeys

\[
\sqrt{B_{j+1}}
\le
\rho_A\sqrt{B_j}
+
\sqrt{B_{Q_j}}.
\]

The geometric iteration is therefore identical to the pure-heat proof:

\[
\boxed{
\max_j\sqrt{B_{Q_j}}
\ge
(1-\rho_A-o(1))\sqrt m.
}
\]

Hence an order-`m` pulse still localizes to one matched block after affine-linear feedback is moved into the homogeneous propagator.

## 5. What remains technical

The reduction above isolates the exact remaining implementation task:

1. choose the co-deforming Gaussian covariance and amplitude variables;
2. prove the localized/weighted operator estimate for `L_A` with accumulated norm controlled by the existing affine-action ledger;
3. verify that far harmonic pressure or nonlocal tail terms are either included with bounded action or explicitly routed to the pressure-degeneration branch;
4. record the resulting `C_A(K)` and select a fixed `c(K)` with `rho_A<1`.

No exact diagonalization of the full affine propagator is required for the localization argument.
