# Sharp Gagliardo--Nirenberg consolidation of the vorticity-source estimate

Date: 2026-08-13

Status: **AUDIT CORRECTION / CANONICAL SHARP-INEQUALITY REFACTORING**.

The previous source-gap work factored the scalar estimate through

\[
L^2\to L^3\to L^6\to\dot H^1.
\]

That factorization is valid and useful diagnostically, but it is not the cleanest way to state the best scalar interpolation constant.  The canonical estimate should use the **sharp Gagliardo--Nirenberg inequality directly**.

External anchors for sharp Gagliardo--Nirenberg interpolation and optimizers include:

- Michael I. Weinstein, *Nonlinear Schrödinger equations and sharp interpolation estimates*, Communications in Mathematical Physics 87 (1983), 567--576;
- Jian-Guo Liu and Jinhuan Wang, *On the best constant for Gagliardo-Nirenberg interpolation inequalities* (2017), which covers a general family containing the `d=3`, gradient-`L2`, lower-`L2`, target-`L3` case.

This note changes the **bookkeeping hierarchy**, not the underlying exact palinstrophy decomposition.

---

## 1. Scalar sharp GN inequality

For

\[
\rho\in H^1(\mathbb R^3),
\]

the scale-invariant inequality has the form

\[
\boxed{
\|\rho\|_3
\le
C_{\rm GN}
\|\rho\|_2^{1/2}
\|\nabla\rho\|_2^{1/2},
}
\]

or equivalently

\[
\boxed{
\|\rho\|_3^3
\le
C_{\rm GN}^3
\|\rho\|_2^{3/2}
\|\nabla\rho\|_2^{3/2}.
}
\]

The best constant is determined by the associated variational ground-state problem; optimizer families are generated by the standard amplitude/translation/dilation symmetries.

## 2. Apply to vorticity magnitude

Set

\[
\rho=|\omega|,
\qquad
E=\|\omega\|_2^2,
\]

\[
P_{\rm mag}
=\|\nabla|\omega|\|_2^2,
\]

\[
P_{\rm ang}=P-P_{\rm mag},
\qquad
P=\|\nabla\omega\|_2^2.
\]

Then

\[
\boxed{
\|\omega\|_3^3
\le
C_{\rm GN}^3
E^{3/4}
(P-P_{\rm ang})^{3/4}.
}
\]

If

\[
\|S\|_3\le C_R\|\omega\|_3
\]

is the strain/vorticity singular-integral bound, then

\[
|Q|
\le
\|S\|_3\|\omega\|_3^2
\le
C_R\|\omega\|_3^3.
\]

Therefore the canonical source estimate is

\[
\boxed{
|Q|
\le
C_\sharp
E^{3/4}
(P-P_{\rm ang})^{3/4},
\qquad
C_\sharp=C_RC_{\rm GN}^3.
}
\]

Equivalently,

\[
\boxed{
|Q|
\le
C_\sharp
E^{3/4}P^{3/4}
(1-\eta_{\rm ang})^{3/4}.
}
\]

## 3. What remains exact and unchanged

The exact magnitude/direction split remains fundamental:

\[
\boxed{
P=P_{\rm mag}+P_{\rm ang}.
}
\]

Thus directional variation still removes part of the gradient budget from the scalar magnitude channel.  The coefficient

\[
(1-\eta_{\rm ang})^{3/4}
\]

remains in the **sharp-GN formulation**.

The one-variable source/dissipation optimization also remains valid after replacing the old composite source constant by `C_sharp`:

\[
\boxed{
P=4P_{\rm ang}
}
\]

is the optimizer of the derived source/dissipation ratio at fixed `E,P_ang`, and

\[
\boxed{
P_{\rm ang}
>
\frac{27C_\sharp^4}{256\nu^4}E^3
\Longrightarrow
Q<\nu P.
}

## 4. Reclassify the magnitude-heterogeneity channel

The previously derived

\[
\chi_{\rm mag}
\]

and

\[
\mathcal R_{\rm int}
\le(1+\chi_{\rm mag})^{-1/2}
\]

remain mathematically valid for the **factorized interpolation route**

\[
\|\rho\|_3^3
\le
\mathcal R_{\rm int}
\|\rho\|_2^{3/2}
\|\rho\|_6^{3/2}.
\]

However one must **not** multiply the sharp GN constant by the old interpolation deficit without proving a separate sharp-GN stability/refinement inequality.

Therefore:

- `chi_mag` remains a DSD magnitude-distribution diagnostic;
- it remains useful for multicore within/between variance decomposition;
- it explains one reason the elementary interpolation/Sobolev chain fails to saturate;
- it is **not** treated as an automatic multiplicative factor on top of `C_GN`.

## 5. Reclassify the separate sharp-Sobolev gap

The compactness/sharp-Sobolev note is also a valid statement about that individual inequality, but the canonical source proof no longer needs to optimize

1. `L2-L3-L6` interpolation and
2. sharp Sobolev

as two independent constants.

They are replaced by the single sharp GN variational problem.

The correct compactness-rigidity question becomes

\[
\boxed{
\text{Can the normalized vorticity magnitude approach the sharp GN optimizer manifold?}
}
\]

rather than asking whether two separate inequalities can both saturate.

## 6. Compactness route with sharp GN

Let

\[
f_j=\chi|\Omega_j|
\]

on a fixed normalized buffered ball.

If the bounded V2 branch gives strong local `H1` compactness and the source requires the **sharp GN ratio** to approach one, then the limiting/scaled profile must approach the sharp GN optimizer family modulo the inequality's symmetries.

Because the normalized window fixes a physical scale and center only partially, translation/dilation modulation must be handled explicitly; it must not be assumed compact without fixing those parameters.

Thus the new rigidity target is a standard near-extremizer problem:

\[
\boxed{
\text{sharp-GN near optimizer}
+\text{divergence-free vector geometry}
+\text{projective/polarity constraints}
\Longrightarrow
\text{strict incompatibility?}
}
\]

This is cleaner than treating elementary interpolation and Sobolev saturation separately.

## 7. Update the source certificate

There are now two distinct certificates.

### Canonical sharp-GN certificate

Define

\[
\boxed{
\mathfrak D_{\rm GN}
=
\frac{\nu^4P}
{C_\sharp^4E^3(1-\eta_{\rm ang})^3}.
}
\]

Then

\[
\boxed{
\mathfrak D_{\rm GN}>1
\Longrightarrow
Q<\nu P
\Longrightarrow
\dot E<0.
}
\]

### Factorized diagnostic certificate

The older certificate involving

\[
(1+\chi_{\rm mag})^2
\]

remains valid **with the older composite interpolation/Sobolev chain constant**, not with `C_sharp` unless a sharp-GN deficit theorem is separately supplied.

The repository must keep those two constants/claims typed separately.
