# Pressure-Hessian fluctuation self-closure modulo a parent-scale harmonic tail

Date: 2026-08-13

Status: **DERIVED LOCAL PRESSURE-RESIDUAL CLOSURE / PARENT HARMONIC TAIL CASCADE OPEN**.

The Gaussian residual-variance equation previously retained pressure-Hessian fluctuation as a potentially independent additive forcing.  The pressure Poisson equation shows that this is too coarse.

After subtracting the self-consistent affine mean gradient, the spatially varying part of the local pressure source is generated by the residual gradient itself.  Hence the near pressure-Hessian fluctuation is multiplicative in the four-channel residual state.  Only the pressure field generated outside the local buffer remains as a parent-scale harmonic tail.

---

## 1. Pressure Poisson equation and affine split

For incompressible Navier--Stokes,

\[
\boxed{
-\Delta P
=\operatorname{tr}((\nabla U)^2).
}
\]

On a self-consistent Gaussian window write

\[
\nabla U=L+B,
\qquad
\int\gamma B=0,
\]

with

\[
\int\gamma|B|^2=\mathcal B_\gamma.
\]

Algebraically,

\[
\boxed{
\operatorname{tr}((\nabla U)^2)
=\operatorname{tr}(L^2)
+2\operatorname{tr}(LB)
+\operatorname{tr}(B^2).
}
\]

The first term is spatially constant.  A constant Poisson source produces a quadratic pressure with spatially constant Hessian, and therefore disappears from a pressure-Hessian **variance** after subtracting the local/Gaussian Hessian mean.

Thus the varying local pressure source is produced only by

\[
\boxed{L\times B\quad\text{and}\quad B\times B.}
\]

---

## 2. Local buffer decomposition

Choose an ellipsoidal or comparable Euclidean buffer `2E` containing the main Gaussian mass and a cutoff `chi=1` on the inner observation region `E`.

Split the pressure as

\[
P=P_{\rm near}+P_{\rm far}+P_{\rm const},
\]

where

- `P_const` is a local quadratic particular solution for the chosen constant source representative;
- `P_near` is generated by the cutoff varying source
  \[
  \chi\{2\operatorname{tr}(LB)+\operatorname{tr}(B^2)-c_B\};
  \]
- `P_far` is harmonic on the inner region `E`.

Here `c_B` is any convenient local constant representative; its exact value affects only the constant-Hessian sector.

Therefore

\[
\boxed{
\nabla^2P-(\nabla^2P)_\gamma
=
[\nabla^2P_{\rm near}-(\nabla^2P_{\rm near})_\gamma]
+
[\nabla^2P_{\rm far}-(\nabla^2P_{\rm far})_\gamma].
}
\]

## 3. Small-residual moment bound for the gradient defect

The antisymmetric part of `B` is proportional to the vorticity fluctuation, which is bounded pointwise under first hitting.  The symmetric part is a mean-free strain fluctuation with uniform BMO control.

Let

\[
B_2=\int\gamma|B|^2=\mathcal B_\gamma.
\]

The BMO-small-variance tail estimate gives, on a bounded-condition Gaussian/buffer,

\[
\boxed{
\|B\|_{L^4}^2
\le
C_K B_2^{1/2}
\left[1+\log\frac{C_K}{B_2}\right]
}
\]

for small `B2`, with a harmless bounded replacement when `B2` is not small.

Consequently

\[
\boxed{
\|2\operatorname{tr}(LB)\|_2
\le C|L|B_2^{1/2},
}
\]

and

\[
\boxed{
\|\operatorname{tr}(B^2)-c_B\|_2
\le
C_KB_2^{1/2}
\left[1+\log\frac{C_K}{B_2}\right].
}
\]

## 4. Near pressure Hessian closes into the residual state

The Hessian of the Newtonian potential is a zero-order Calderon--Zygmund operator on the cutoff source.  Interior/buffer estimates therefore give

\[
\boxed{
\Pi_{P,\rm near}
\le
C_K\sqrt{\mathcal B_\gamma}
\left[
|L|+1+
\log\frac{C_K}{\mathcal B_\gamma}
\right],
}
\]

where

\[
\Pi_{P,\rm near}^2
=\int\gamma
|\nabla^2P_{\rm near}-(\nabla^2P_{\rm near})_\gamma|^2.
\]

Hence the pressure contribution in the strain-variance equation obeys

\[
\boxed{
\sqrt{V_S}\,\Pi_{P,\rm near}
\le
C_K\mathcal B_\gamma
\left[
|L|+1+
\log\frac{C_K}{\mathcal B_\gamma}
\right].
}
\]

Thus the **near pressure-Hessian fluctuation is not an independent additive source**.  It has the same multiplicative/Osgood structure as the residual self-interaction.

## 5. The only independent pressure remainder is harmonic on the child window

Define

\[
H_P=\nabla^2P_{\rm far}.
\]

Since `P_far` is harmonic in the inner region, every component of `H_P` is harmonic there.

The remaining pressure variance is

\[
\boxed{
\Pi_{P,\rm far}^2
=\int\gamma|H_P-(H_P)_\gamma|^2.
}
\]

Interior harmonic estimates imply that oscillation of `H_P` on a child region is smaller than its oscillation/size on a larger parent region by a scale-ratio factor.  Schematically, for child radius `r` and parent radius `R>>r`,

\[
\boxed{
\operatorname{osc}_{B_r}H_P
\lesssim
\frac rR\,
\mathcal H_P(B_R),
}
\]

where `H_P(B_R)` is a parent-scale pressure-Hessian size/oscillation descriptor.

Therefore a large child pressure-Hessian variance generated by remote sources requires a correspondingly large parent-scale pressure descriptor.

## 6. Revised residual Osgood inequality

After absorbing the near pressure term into the residual self-interaction, the four-channel state obeys schematically

\[
\boxed{
\mathcal B_\gamma'
\le
C_K(1+|\operatorname{sym}L|)
\mathcal B_\gamma
\left[1+\log\frac{C_K}{\mathcal B_\gamma}\right]
+C_K\sqrt{\mathcal B_\gamma}\,\Pi_{P,\rm far}
}
\]

apart from favorable viscous terminal coercivity.

Hence small residual state can be generated rapidly only by

1. enough multiplicative residual/affine action, or
2. a large **parent-scale harmonic pressure tail**.

Pressure is no longer an untyped local forcing channel.

---

## 7. Parent-scale escalation rule

If

\[
\Pi_{P,\rm far}
\]

is above the allowed child threshold, enlarge the observation region and recompute the affine/Gaussian state.

At the parent scale one of two things happens:

- the pressure source becomes resolved and enters `L x B` or `B x B`, hence the four-channel Osgood state;
- the pressure tail remains remote, in which case the scale is enlarged again.

Thus the pressure route becomes an adaptive scale cascade rather than an independent local escape.

The unresolved question is whether this escalation can continue through arbitrarily many parent scales while respecting kinetic-energy, local-energy, and first-hitting constraints.

## 8. DSD interpretation

Pressure is nonlocal, but its **locally distinguishable variation** is not arbitrary.

At each resolution:

\[
\boxed{
\text{pressure-Hessian variation}
=
\text{resolved residual-generated part}
+
\text{harmonic parent tail}.
}
\]

The first part is already encoded by the current four-channel state.  Only information not resolvable at the current scale is promoted to the next parent scale.
