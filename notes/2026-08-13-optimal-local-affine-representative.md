Date: 2026-08-13

Status: **EXACT WEIGHTED ORTHOGONAL DECOMPOSITION + DEFORMATION-COST LOWER BOUND / SHARPENS THE REMOTE-AFFINE BOOKKEEPING**.

The earlier affine-background notes extracted a common affine gradient from the remote/intermediate field.  That decomposition is useful for locality, but it leaves an artificial possibility that a large remote affine factor is cancelled by an opposite near-field affine component.

For the actual compactness/deformation ledger, the more economical DSD choice is to aggregate **all resolved scales first** and then select the best affine representative of the **total local velocity gradient**.

With this choice, a large affine condition number cannot be a bookkeeping artefact: it must carry an explicit local `L2` strain/gradient-energy cost.

## 1. Weighted observation window

Let

\[
\phi\ge0
\]

be a fixed smooth spatial observation weight with

\[
M_\phi=\int\phi\,dz>0.
\]

On a normalized first-hitting window, let `U(z,s)` be the total velocity after removing only the spatially constant translation channel.

Define the weighted affine representative

\[
\boxed{
L_\phi(s)
=\frac1{M_\phi}
\int\phi(z)\,\nabla U(z,s)\,dz.
}
\]

Because incompressibility gives

\[
\operatorname{tr}\nabla U=0
\]

pointwise,

\[
\boxed{\operatorname{tr}L_\phi=0.}
\]

Thus its affine flow is volume preserving.

## 2. Best constant-matrix approximation

For any constant matrix `L`, define

\[
\mathcal E_\phi(L)
=\int\phi|\nabla U-L|_F^2dz.
\]

Differentiating with respect to `L`, or completing the square, gives

\[
\boxed{
L_\phi
=\operatorname*{argmin}_{L\in\mathbb R^{3\times3}}
\mathcal E_\phi(L).
}
\]

Since `L_phi` is already trace free, the same minimizer applies if one restricts to trace-free constant matrices.

Define the residual gradient

\[
\boxed{B_\phi=\nabla U-L_\phi.}
\]

Then exactly

\[
\boxed{
\int\phi B_\phi\,dz=0.
}
\]

## 3. Exact weighted Pythagorean identity

Expanding the square and using the zero weighted mean of `B_phi`,

\[
\begin{aligned}
\int\phi|\nabla U|^2
&=\int\phi|L_\phi+B_\phi|^2\\
&=M_\phi|L_\phi|^2
+2L_\phi:\int\phi B_\phi
+\int\phi|B_\phi|^2.
\end{aligned}
\]

Hence

\[
\boxed{
\int\phi|\nabla U|^2
=M_\phi|L_\phi|^2
+\int\phi|\nabla U-L_\phi|^2.
}
\]

This is an exact static-aggregation decomposition into

1. coherent affine gradient content;
2. non-affine local variance.

No near/far cancellation is hidden between the two terms because all scales were summed before the projection.

## 4. Rotation versus strain

Split

\[
L_\phi=S_\phi+A_\phi,
\]

where

\[
S_\phi^T=S_\phi,
\qquad
A_\phi^T=-A_\phi.
\]

The antisymmetric part is a common rigid rotation and can be removed by an orthogonal frame without changing Euclidean norms or viscosity.

The symmetric part is the coherent affine deformation channel.

Because the symmetric/antisymmetric matrix spaces are orthogonal,

\[
|L_\phi|^2=|S_\phi|^2+|A_\phi|^2.
\]

In particular,

\[
\boxed{
M_\phi|S_\phi|^2
\le
\int\phi|\nabla U|^2.
}
\]

## 5. Affine deformation generated by the representative

Let

\[
F_\phi'=L_\phi F_\phi,
\qquad
F_\phi(s_0)=I.
\]

Then

\[
\det F_\phi=1.
\]

For any material vector transported only by this affine representative,

\[
\frac d{ds}\log|F_\phi v|
=e^TS_\phi e
\]

with `e=F_phi v/|F_phi v|`.

The singular-value inequalities imply

\[
\frac d{ds}\log\kappa(F_\phi)
\le
\lambda_{\max}(S_\phi)-\lambda_{\min}(S_\phi)
\le C_3|S_\phi|_F,
\]

where one may take a dimension-only constant such as `C_3=sqrt(2)` for a crude Frobenius bound.

Therefore

\[
\boxed{
\log\kappa(F_\phi(s_1))
\le
C_3\int_{s_0}^{s_1}|S_\phi(s)|ds.
}
\]

## 6. Condition-number lower bound on local strain energy

Let

\[
T=s_1-s_0>0.
\]

Cauchy--Schwarz gives

\[
\left(\int_I|S_\phi|ds\right)^2
\le
T\int_I|S_\phi|^2ds.
\]

Combining with the weighted Pythagorean identity,

\[
\int_I\int\phi|\nabla U|^2dzds
\ge
M_\phi\int_I|S_\phi|^2ds.
\]

Hence

\[
\boxed{
\int_I\int\phi|\nabla U|^2dzds
\ge
\frac{M_\phi}{C_3^2T}
\bigl[\log\kappa(F_\phi(s_1))\bigr]^2.

\]

Thus

\[
\boxed{
\kappa(F_\phi)\to\infty
\Longrightarrow
\text{normalized local gradient-energy concentration}.
}
\]

A large affine condition number is no longer an independent abstract escape route.

## 8. Relation to the earlier remote-affine factorization

\[
\boxed{

Thus the exact factorization

\[

This is the preferred DSD bookkeeping convention going forward.
