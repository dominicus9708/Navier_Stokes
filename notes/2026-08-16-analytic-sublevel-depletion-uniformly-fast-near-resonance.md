## 1. Turnover-scale phase

On the frozen coherent-rotation block use turnover coordinates and helical inertial-wave frequencies

\[
\omega_s(k)=s\frac{k_\parallel}{|k|},
\qquad s\in\{+,-\}.
\]

For a quadratic pair `(p,q)` with output `k=p+q`, define

\[
\boxed{
\Phi(p,q)
=
\omega_{s_p}(p)
+\omega_{s_q}(q)
-\omega_{s_k}(p+q).
}
\]

Fast rotation multiplies this phase by the large turnover parameter `R`.

A contribution that remains secular over `O(R)` turnover blocks must therefore concentrate in a detuning window

\[
\boxed{|\Phi|\lesssim R^{-1}}
\]

unless time derivatives/high-frequency modulation generated by integration by parts become large.

## 2. Compact turnover-frequency block

Fix constants

\[
0<c_0<C_0<\infty
\]

and restrict to

\[
c_0\le |p|,|q|,|p+q|\le C_0.
\]

If desired, also impose the uniformly-fast input condition

\[
|p_\parallel|/|p|\ge\delta_f,
\qquad
|q_\parallel|/|q|\ge\delta_f.
\]

On this compact set all denominators are separated from zero and `Phi` is a real-analytic algebraic function of `(p,q)`.

For every fixed helicity triple it is not identically zero on any open subset. Indeed, if `Phi` vanished on an open pair-frequency set, differentiating in `p` and varying `q` would force the inertial-wave group velocity `nabla omega(k)` to be locally constant on an open set, which is false for `omega(k)=s k_parallel/|k|` away from the excluded zero-frequency singularity.

## 3. Analytic sublevel estimate

A standard Lojasiewicz / real-analytic sublevel estimate on the compact pair-frequency block therefore gives constants

\[
C<\infty,
\qquad
\alpha>0
\]

(depending only on the fixed annulus, fast-angle cutoffs and the finite helicity branch) such that for all sufficiently small `delta`,

\[
\boxed{
\big|
\{(p,q):|\Phi(p,q)|\le\delta\}
\big|
\le C\delta^\alpha.
}
\]

No uniform lower bound on `|nabla Phi|` is assumed.

This is important because inertial/helical wave resonances can possess Van-Hove critical points where group velocities agree and ordinary coarea transversality degenerates. Such critical points can worsen the exponent but, on the present fixed compact analytic block, do not make the phase identically zero on an open six-dimensional set.

## 4. Spatial tightness converts sublevel measure to source depletion

Let the turnover-scale localized gradient packets be `G_1,G_2`, supported (after a harmless fixed Gaussian-tail truncation) in a fixed spatial ball.

Then

\[
\|G_i\|_1\le C\|G_i\|_2,

\[
\|\widehat G_i\|_\infty

On the fixed frequency block all quadratic helical multipliers are bounded. Hence the contribution from the detuning slab `|Phi|<=delta` obeys schematically

\[
\boxed{

C\delta^\alpha

If only `L2` pair control is used, one may lose part of the exponent, but still obtains a positive power `delta^alpha_*` with `alpha_*>0`; the argument requires only positivity of the exponent.

## 6. Van-Hove singularities are typed, not ignored

The usual coarea estimate

\[
|\{|\Phi|\le\delta\}|
\sim
\delta\int_{\Phi=0}|\nabla\Phi|^{-1}dS

can fail to have a uniform constant at group-velocity critical points.

The present proof does not discard those points. It uses only the weaker fact that the compact inertial-wave phase is a nonzero real-analytic function, so its small sublevel set has vanishing measure with some positive power.

Hence resonance Van-Hove singularities may degrade the gain but cannot support an `O(1)` fraction of a **spatially tight compact-frequency packet** in windows of width `R^-1` without an additional concentration mechanism.

## 7. Remaining escape routes

A surviving fast-rotation source must therefore leave at least one hypothesis of the compact-tight lemma:

1. **low-frequency escape:** one triad member tends toward zero turnover frequency magnitude;
2. **high-frequency escape:** one member leaves every fixed turnover annulus;

4. **time/frequency modulation:** the packet changes fast enough that oscillatory integration by parts generates derivative/time-variation terms;
5. **symmetric-affine / axis variation:** the frozen rigid-rotation approximation fails, already typed by strain/projective/deformation ledgers.
