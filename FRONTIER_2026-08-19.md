## 1. Exact middle-strain saturation defect

Let

\[
f=\lambda_2^+.
\]

On `lambda_2>0`,

\[
\boxed{
-\det S
=\frac12\lambda_2|S|^2-\lambda_2^3.
}
\]

Hence globally

\[
\boxed{
-\det S
\le
\frac12 f|S|^2-f^3.
}
\]

The old determinant bound loses the exact nonnegative cubic defect `f^3`.

The enstrophy ledger becomes

\[
\boxed{
\frac12E_\omega'
+4\|f\|_3^3
\le
\left(C_S\|f\|_{3/2}-\nu\right)P_\omega.
}
\]

Positive enstrophy growth therefore requires the instantaneous critical barrier

\[
\boxed{
\|\lambda_2^+\|_{3/2}>\nu/C_S.
}
\]

## 2. Near determinant saturation has a strict power cost

For a local cutoff `phi`, define

\[
A_\phi=\int\phi f|S|^2,
\qquad
Q_\phi=\int\phi f^3,
\qquad
\delta_\phi=Q_\phi/A_\phi.
\]

Using the exact local Betchov shell identity and the production-weighted variable `x=f/|S|`, a fresh local stretching pulse `P0` with subdominant shell flux satisfies

\[
\boxed{
E_\omega P_\omega
\gtrsim
P_0^{4/3}\delta_\phi^{-2/3}.
}
\]

Thus

\[
\boxed{
\max\{E_\omega,P_\omega\}
\gtrsim
P_0^{2/3}\delta_\phi^{-1/3}.
}
\]

So `delta_phi -> 0` is not a free efficiency limit: it forces enstrophy or palinstrophy to diverge by an explicit power unless shell transport is already order one.

## 5. H is a saturation ratio, not merely a large derivative

Use the Miller strain--vorticity interaction regularity anchor and define

\[
\mathfrak R_H
=
\frac{
\left\|P_{st}\left((u\cdot\nabla)S+S^2+\frac34\omega\otimes\omega\right)\right\|_2

\|\Delta S\|_2

\]

Let

\[
A=\|S\|_2,
\quad
B=\|\Delta S\|_2,
\quad
K=\|u\|_2.

Interpolation gives

\[
\boxed{
\mathfrak R_H
\lesssim
K^{1/4}A^{7/8}B^{-1/8}

Hence dangerous derivative saturation requires

\[
\boxed{
B\lesssim K^2A^7+A^5.

Arbitrarily fast derivative-only escape is therefore perturbative rather than dangerous if the lower norms do not co-grow.

## 7. Exact advection H1 identity

For each strain component let

\[
g^{ab}=\nabla S_{ab}.
\]

Then

\[
\boxed{
\langle(u\cdot\nabla)S,-\Delta S\rangle
=
\sum_{a,b}\int(g^{ab})^TSg^{ab}\,dx.
}
\]

The strain `H1` equation contains the negative of this contraction, so advection-driven derivative growth is caused by compression of strain gradients, not by translation or rigid rotation.

On the near-planar strain geometry

\[
\lambda_1\simeq-\lambda_3,
\qquad
\lambda_2\simeq0^+,

\[
\boxed{

\qquad
\nabla S\text{ loaded toward the compressive }e_1\text{ axis}.
}
\]

## 8. Strain-gradient projective covariance

Define

\[
G_S
=\sum_{a,b}\nabla S_{ab}\otimes\nabla S_{ab},
\qquad
C_{\nabla S}=G_S/|\nabla S|^2.
\]

Then

\[
\boxed{
\langle(u\cdot\nabla)S,-\Delta S\rangle
=
\int\operatorname{tr}(S G_S)dx.
}
\]

Let

\[
J_{\nabla S}
=1-\operatorname{tr}(C_{\nabla S}^2).
\]

Because `tr S=0`,

\[
\boxed{
|\operatorname{tr}(S G_S)|
\le
|S||\nabla S|^2
\sqrt{\frac23-J_{\nabla S}}.
}
\]

Thus isotropic strain-gradient covariance (`J_{nabla S}=2/3`) exactly depletes the advection contribution.

Dangerous advection-H requires persistent projective anisotropy and compressive eigenframe bias.
