## 1. Pressure Poisson equation

The similarity velocity equation used throughout M17 is

\[
D_B U = \Delta U - U/2 - \nabla P,
\qquad
B = U + y/2.
\]

Taking divergence and using incompressibility gives

\[
\boxed{
-\Delta P = \operatorname{tr}(A^2),
\qquad A = \nabla U.
}
\]

Write

\[
A = \Sigma + \Omega.
\]

Since the antisymmetric part generated by vorticity satisfies

\[
\operatorname{tr}(\Omega^2) = -\rho^2/2,
\]

we obtain

\[
\boxed{
-\Delta P = |\Sigma|^2 - \rho^2/2.
}
\]

Define

\[
\boxed{
S_P := |\Sigma|^2 - \rho^2/2.
}
\]

Then

\[
P = (-\Delta)^{-1} S_P
\]

up to the usual pressure gauge.

## 4. First far mode visible to DSAIG

DSAIG sees

\[
(p\cdot\nabla_h)\nabla_h^2 P_{far}.
\]

The mode-by-mode effect is:

- degree 0: Hessian vanishes;
- degree 1: Hessian vanishes;
- degree 2: Hessian is constant, so its directional derivative vanishes;
- degree 3: Hessian is linear, so its directional derivative is generically a nonzero constant tensor;
- degree 4 and above: higher spatially varying contributions remain.

Therefore

\[
\boxed{
N_p^{far}
=N_{p,3}^{far}+N_{p,4}^{far}+\cdots.
}
\]

The far pressure quadrupole affects strain evolution, but not the DSAIG derivative-alignment forcing.
