\[

\[

## 2. Local/ambient strain decomposition

Let \(\chi_\ell\) be a fixed-profile cutoff equal to one on the packet corridor and supported in a fixed-factor enlarged buffer.

The strain is a linear Calderon--Zygmund transform \(\mathcal T\) of vorticity. Define

\[
\boxed{
\Sigma_{loc}:=\mathcal T(\chi_\ell W),
\qquad
\Sigma_{amb}:=\mathcal T((1-\chi_\ell)W).
}
\]

Then

\[
\Sigma=\Sigma_{loc}+\Sigma_{amb}.
\]

No claim is made that the two cutoff vorticity pieces are separately material solutions; this is only a linear source decomposition of the instantaneous strain.

## 3. L2 Calderon--Zygmund bound

The whole-space CZ estimate gives

\[
\boxed{
\|\Sigma_{loc}(\tau)\|_2
\le C_{CZ}
\|\chi_\ell W(\tau)\|_2.
}
\]

Assume the packet mass remains within a fixed factor of its observation-time value over the short corridor; failure is already a mass-turnover/interface branch of M17-225--226.

\[
\|\chi_\ell W(\tau)\|_2^2
\le C_M M_0.
\]

Hence

\[
\boxed{
\int_0^{c_t\ell^2}
\|\Sigma_{loc}(\tau)\|_2^2d\tau

}
\]

## 4. Bound the local self-strain action

The spacetime volume of the packet corridor is \(O(\ell^5)\).

By spacetime Cauchy--Schwarz,

\[
\begin{aligned}
\int_0^{c_t\ell^2}
\int_{P(\tau)}|\Sigma_{loc}|dy\,d\tau
&\le
C\ell^{5/2}
\left(
\int_0^{c_t\ell^2}\|\Sigma_{loc}\|_2^2d\tau
\right)^{1/2}\\
&\le
C\ell^{5/2}(\ell^2M_0)^{1/2}\\
&=C\ell^{7/2}M_0^{1/2}.
\end{aligned}
\]

Therefore the normalized local action satisfies

\[
\boxed{
\mathcal S_{loc}
\le
C\ell^{1/2}M_0^{1/2}.
}
\]

For a mean-dominated packet

\[
M_0\asymp a^2\ell^3,
\qquad
a:=|\bar W|,
\]

so

\[
\boxed{
\mathcal S_{loc}
\le C a\ell^2.
}
\]
