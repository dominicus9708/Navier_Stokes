\boxed{

The first local source coefficient visible to DSAIG is `S_1`.

## 6. Source gradient at the nodal core

Differentiate

\[
S_P=|\Sigma|^2-\frac12|W|^2.
\]

Because

\[
W(0)=0,
\]

we have

\[
\boxed{
\nabla |W|^2(0)=0.
}
\]

Hence

\[
\boxed{
s=\nabla S_P(0)=2\Sigma:\nabla\Sigma.}
\]

For a horizontal derivative `partial_a`, at the core

\[
\Sigma=\operatorname{diag}(\lambda,\lambda,-2\lambda).
\]

Thus

\[
\begin{aligned}
s_a
&=2\lambda\partial_a\Sigma_{11}
+2\lambda\partial_a\Sigma_{22}
-4\lambda\partial_a\Sigma_{33}.
\end{aligned}
\]

Since incompressibility gives

\[
\operatorname{tr}\Sigma=0
\]

identically,

\[
\partial_a\Sigma_{11}
+\partial_a\Sigma_{22}
=-\partial_a\Sigma_{33}.
\]

Therefore

\[
\boxed{
s_a=-6\lambda\,\partial_a\Sigma_{33}.}
\]

Equivalently,

\[
\boxed{
s_h=-6\lambda\nabla_h\Sigma_{33}.}
\]

This uses only the pointwise core eigenvalue structure plus the global trace-free identity; no neighborhood isotropy is assumed.
