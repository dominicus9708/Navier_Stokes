## 1. Problem

M19-193 decomposed the coarse aperiodic necessary condition using finite constants \(K_I,\Gamma_*,W_*\). If these symbols are interpreted merely as any admissible upper bounds, the decomposition is meaningless: every admissible upper bound can be enlarged arbitrarily without changing the solution.

Therefore the finite-high split must be defined with intrinsic least ceilings.

## 2. Canonical least ceilings

On a retained W1 recurrent corridor define

\[
K^\sharp:=\sup_s\|\Omega(s)\|_{L^\infty},
\]

\[
\Gamma^\sharp:=\sup_{s,R}\Gamma_R(s),
\qquad
\Gamma_R(s):=
\frac{R\|\nabla(U-m_R)\|_{L^2(A_R^*)}}
{\|U-m_R\|_{L^2(A_R^*)}},
\]

and

\[
W^\sharp:=\sup_s\|U(s)\|_{L^{3,\infty}}.
\]

These are the least admissible ceilings whenever finite. If a supremum is not attained, it is approached by a sequence and all threshold statements below are understood in that sequential sense.

## 3. Intrinsic severity

The only canonical version of the M19-192/193 multiplicative severity is

\[
\boxed{
\Xi_{W1}^\sharp
:=
\frac{K^\sharp(\Gamma^\sharp W^\sharp)^3}{\nu^3}.
}
\]

The implication obtained earlier must therefore be read as

\[
\boxed{
\text{genuinely aperiodic recurrent hard dynamics}
\Longrightarrow
\Xi_{W1}^\sharp\ge \Xi_c,
}
\]

with \(\Xi_c>0\) the hard-dimension threshold produced by the collective trace estimate.

## 4. Correct finite-high trichotomy

For fixed positive thresholds \(k_0,\gamma_0,w_0\) satisfying

\[
k_0(\gamma_0w_0)^3<\nu^3\Xi_c,

\[
\boxed{
K^\sharp\ge k_0
\quad\lor\quad
\Gamma^\sharp\ge\gamma_0
\quad\lor\quad
W^\sharp\ge w_0.
}
\]

This is now invariant under arbitrary re-labeling of corridor bounds.
