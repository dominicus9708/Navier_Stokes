## 2. One-dimensional quotient flow

Let

\[
\mathcal K
\]

be a connected compact recurrent component after quotienting rotations.

If its center tangent is one-dimensional and generated by the vector field itself, then locally the recurrent dynamics lies on a one-dimensional `C1` invariant manifold.

A `C1` autonomous flow on a one-dimensional manifold has only two recurrent possibilities:

1. an equilibrium;
2. a periodic orbit on a circle component.

Indeed, on an interval a nonstationary orbit is monotone and cannot be recurrent, while on a circle a nowhere-vanishing one-dimensional vector field traverses the circle with a finite exact return time.

Hence

\[
\boxed{
\text{recurrent quotient component}
\Longrightarrow
\text{equilibrium}
\lor
\text{periodic orbit}.
}
\]

In particular, genuinely quasiperiodic or higher-rank aperiodic recurrence is impossible once the quotient center is one-dimensional.

## 3. Lift an equilibrium of the rotation quotient

Suppose the quotient state is fixed.

Then the original similarity solution remains on a single rotation orbit:

\[
U(s)=Q(s)U_0.
\]

Because the Navier--Stokes similarity flow is autonomous and `SO(3)`-equivariant, the group motion along a one-state quotient orbit is a one-parameter subgroup modulo the isotropy of `U_0`.

Thus one may write, after choosing an axis generator `A in so(3)`,

\[
\boxed{
U(s,y)
=Q_{\alpha s}U_0(Q_{-\alpha s}y)
}
\]

for a constant angular rate `alpha`, up to an isotropy/gauge normalization.

This is exactly the rotated backward self-similar (RSS) class.

The special case

\[
\alpha=0
\]

is ordinary backward self-similarity.

Therefore

\[
\boxed{
\text{equilibrium in }\mathcal H/SO(3)
\Longrightarrow
\text{RSS}.
}
\]

## 4. Lift a periodic orbit of the rotation quotient

Suppose instead the quotient orbit has exact period

\[
S>0.
\]

Then after one quotient period the full state may return only up to a fixed rotation:

\[
\boxed{
U(s+S)=Q_*\cdot U(s)
}
\]

for some

\[
Q_*\in SO(3).
\]

By equivariance the same `Q_*` repeats on every cycle, so

\[
U(s+nS)=Q_*^n\cdot U(s).
\]

Every rotation in `SO(3)` has an axis-angle representation. Write

\[
Q_*=\exp(S\alpha A)
\]

for an axis generator `A` and angular rate `alpha` defined modulo the usual `2pi/S` winding ambiguity.

Then the physical solution is invariant under a discrete combined scaling-and-rotation operation.

This is precisely the rotated discretely self-similar (RDSS) class.

If

\[
Q_*=I,
\]

it reduces to ordinary DSS.

Therefore

\[
\boxed{
\text{periodic quotient orbit}
\Longrightarrow
\text{RDSS},
}
\]

with ordinary DSS as the zero-holonomy special case.
