## 2. Push the fixed label measure to kappa-space

Define

\[
\boxed{

:=
\int\delta(k-\kappa_\lambda(\theta))d\mu_0(\lambda),
}

\[
\boxed{

\int h_\lambda(\theta)

For a smooth test function `psi`,

\[
\frac d{d\theta}
\int\psi(\kappa_\lambda)d\mu_0

\[
\boxed{
