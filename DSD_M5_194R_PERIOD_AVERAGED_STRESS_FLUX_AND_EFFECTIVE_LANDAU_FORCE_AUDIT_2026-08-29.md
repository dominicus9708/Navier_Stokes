## 1. Purpose

M5-194Q reduces a strongly asymptotically homogeneous periodic tail to a stationary leading coefficient which is either zero or Landau.

A tempting shortcut is:

> the original Navier--Stokes problem is unforced, so the Landau point-force coefficient must vanish.

That inference is not valid at the level of the **period-averaged Leray profile equation**.

The similarity scaling term creates an effective distributed source whenever the averaged profile is not exactly spatially `(-1)`-homogeneous through the whole space.

## 2. Period average

Let the similarity profile be periodic:

\[
V(Y,s+S)=V(Y,s).
\]

Define

\[
\bar V(Y)
:=
\frac1S\int_0^S V(Y,s)\,ds,
\]

\[
\overline{V\otimes V}(Y)
:=
\frac1S\int_0^S V(Y,s)\otimes V(Y,s)\,ds,
\]

and similarly `bar P`.

Averaging

\[
V_s-\Delta V
+\frac12V
+\frac12(Y\cdot\nabla)V
+\nabla\cdot(V\otimes V)
+\nabla P=0
\]

over one period removes `V_s` and gives

\[
\boxed{
-\Delta\bar V
+\nabla\cdot\overline{V\otimes V}
+\nabla\bar P
+
\frac12\left(
\bar V+Y\cdot\nabla\bar V
\right)
=0.
}
\]

---

## 3. Define the averaged stress tensor

Use the symmetric incompressible stress convention

\[
\boxed{
\mathbb T_{ij}
:=
-\left(
\partial_j\bar V_i
+\partial_i\bar V_j
\right)
+
\overline{V_iV_j}
+
\bar P\,\delta_{ij}.
}
\]

Because

\[
\nabla\cdot\bar V=0,
\]

we have

\[
\partial_j\mathbb T_{ij}
=
-\Delta\bar V_i
+\partial_j\overline{V_iV_j}
+\partial_i\bar P.
\]

Therefore the averaged Leray equation becomes

\[
\boxed{
\nabla\cdot\mathbb T
=
-\frac12\mathcal G[\bar V],
}
\]

where

\[
\boxed{
\mathcal G[\bar V]
:=
\bar V+(Y\cdot\nabla)\bar V
}
\]

is the vector spatial homogeneity defect.

## 4. Large-sphere stress flux identity

Define the averaged stress flux through the sphere `S_R` by

\[
\boxed{
F(R)
:=
\int_{|Y|=R}
\mathbb T n\,dS.
}
\]

The divergence theorem gives

\[
\boxed{
F(R)
=
-\frac12
\int_{B_R}
\mathcal G[\bar V](Y)\,dY.
}
\]

For a smooth profile at the origin,

\[
F(R)\to0
\qquad(R\downarrow0).
\]

But there is no reason for `F(R)` to remain zero as `R` grows unless the integrated homogeneity defect vanishes.

Thus the Leray scaling term behaves as an effective distributed momentum source.

## 5. Exact homogeneous regions carry no distributed source

If on some region

\[
\bar V(\lambda Y)=\lambda^{-1}\bar V(Y),
\]

then

\[
\mathcal G[\bar V]=0
\]

there.

Hence the stress flux is constant across any annular region in which the profile is exactly `(-1)`-homogeneous and stationary at leading order.

This is precisely the behavior of a Landau far field: once the flow reaches the homogeneous exterior regime, the net momentum flux stops changing with radius.

The value of that constant flux is set by the accumulated defect in the nonhomogeneous interior/transition region.

## 6. Landau coefficient as effective force

For stationary exterior Navier--Stokes flows with a `1/r` leading term, the Landau asymptotic coefficient is classically tied to the net stress/force flux through large spheres.

Accordingly, suppose M5-194Q's asymptotic expansion holds and

\[
\bar V(Y)
=U_b(Y)+o(r^{-1}),
\]

where `U_b` is the Landau solution associated with force vector `b`, with derivative/pressure remainders strong enough to pass the large-sphere stress flux.

Then

\[
\boxed{
F(R)\to b
}
\]

up to the fixed sign convention used in the stress definition.

Combining with the exact Leray identity gives formally

\[
\boxed{
 b
=
-\frac12
\int_{\mathbb R^3}
\mathcal G[\bar V]\,dY
}
\]

whenever the defect is integrable and the asymptotic passage is justified.

Thus the Landau coefficient is not an unexplained external force in similarity variables. It can be generated by the total spatial homogeneity defect of the periodic core and transition region.

## 7. Why the unforced physical equation does not immediately set `b=0`

The physical Navier--Stokes equation is indeed unforced.

But the Leray transformation is time dependent. After averaging in similarity time, its scaling generator remains in the equation.

Therefore

\[
\boxed{
\text{physical external force}=0
\not\Rightarrow
\mathcal G[\bar V]=0.
}
\]

Consequently

\[
\boxed{
\text{physical external force}=0
\not\Rightarrow
F(\infty)=0
}
\]

for the averaged similarity stress without an additional global argument.

The missing information is precisely how the finite-scale core and the escaping physical far field compensate when the blow-up rescaling is taken.

## 9. A useful radial identity for the defect integral

Componentwise,

\[
\int_{B_R}
Y\cdot\nabla\bar V\,dY
=
R\int_{S_R}\bar V\,dS
-3\int_{B_R}\bar V\,dY.
\]

Hence

\[
\boxed{
\int_{B_R}\mathcal G[\bar V]\,dY
=
R\int_{S_R}\bar V\,dS
-2\int_{B_R}\bar V\,dY.
}
\]

For a pure degree `-1` field the two order-`R^2` pieces cancel exactly.

A finite nonzero limit can therefore be encoded in the subleading transition between the smooth core and the homogeneous halo.

This again shows why a crude magnitude estimate is insufficient.
