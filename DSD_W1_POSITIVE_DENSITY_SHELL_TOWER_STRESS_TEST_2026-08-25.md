## 1. Purpose

The Barker--Prange/W1 argument now forces a positive density of log-radius shells carrying fixed positive cubic mass. It is tempting to treat that as an immediate contradiction with bounded enstrophy, bounded frequency, or `Lp`, `p>3`, compactness.

This note shows that such a contradiction does not exist at the level of static function-space estimates.

The construction is deliberately a stress test, not a solution of the nonlinear Leray equation.

## 2. One divergence-free annular template

Choose a nonzero smooth compactly supported divergence-free vector field

\[
\psi\in C_c^\infty(\{1<|Y|<\lambda_0\};\mathbb R^3),
\qquad\nabla\cdot\psi=0,
\]

where `1<lambda_0<Lambda` and `Lambda>lambda_0` is a fixed shell ratio.

Let

\[
R_k=R_0\Lambda^k,
\]

and define

\[
\boxed{
U_k(Y):=R_k^{-1}\psi(Y/R_k).
}
\]

The supports are disjoint annuli.

Set

\[
U_{tail}:=\sum_{k\ge0}U_k.
\]

Because the supports are disjoint, the sum is smooth away from the inner cutoff and all norm calculations reduce to geometric series.

## 3. Fixed cubic mass per shell

Scaling gives

\[
\int|U_k|^3dY
=R_k^{-3}R_k^3\int|\psi|^3dY.
\]

Hence

\[
\boxed{
\|U_k\|_3^3=c_3:=\|\psi\|_3^3>0
}
\]

for every shell.

Therefore the cubic mass up to radius `R_N` is

\[
\boxed{
\int_{|Y|\lesssim R_N}|U_{tail}|^3dY
=(N+O(1))c_3
\asymp\log R_N.
}
\]

This exactly realizes the positive-density/logarithmic Barker--Prange endpoint growth.

## 4. Every p>3 norm is finite and tail-tight

For `p>3`,

\[
\|U_k\|_p^p
=R_k^{3-p}\|\psi\|_p^p.
\]

Thus

\[
\boxed{
\sum_k\|U_k\|_p^p
=\|\psi\|_p^p
\sum_kR_k^{3-p}<\infty.
}
\]

Moreover

\[
\boxed{
\int_{|Y|>R_N}|U_{tail}|^p dY
\asymp R_N^{3-p}\to0.
}
\]

So the tower has exactly the W1 `Lp`, `p>3`, tail tightness.

## 5. Weak-L3 is uniformly critical

On shell `k`,

\[
|U_k|\sim R_k^{-1}
\]

on a set of volume `~R_k^3` wherever the template is nonzero. Hence

\[
\lambda^3|\{|U_{tail}|>\lambda\}|
\]

remains uniformly bounded across the geometric shell ladder. Therefore

\[
\boxed{
U_{tail}\in L^{3,\infty}(\mathbb R^3)
}
\]

while

\[
U_{tail}\notin L^3
\]

because the shell cubic masses are constant.

## 6. Finite enstrophy / Dirichlet energy

One derivative gives

\[
\nabla U_k(Y)=R_k^{-2}(\nabla\psi)(Y/R_k),
\]

so

\[
\|\nabla U_k\|_2^2
=R_k^{-1}\|\nabla\psi\|_2^2.
\]

Hence

\[
\boxed{
\|\nabla U_{tail}\|_2^2
=\|\nabla\psi\|_2^2\sum_kR_k^{-1}<\infty.
}
\]

Since the field is divergence-free, this is equivalent to finite global vorticity enstrophy up to the standard whole-space identity.

Thus positive cubic mass per log shell is exactly compatible with bounded `Z`.

## 7. Campanato and derivative-frequency ratio are scale-independent

For one shell,

\[
\|U_k\|_2^2
=R_k\|\psi\|_2^2.
\]

Therefore the shell Campanato size is

\[
\boxed{
R_k^{-1}\|U_k\|_2^2
=\|\psi\|_2^2.
}
\]

Also

\[
\|\nabla U_k\|_2
=R_k^{-1/2}\|\nabla\psi\|_2,
\]

so

\[
\boxed{
\Gamma_k
:=\frac{R_k\|\nabla U_k\|_2}{\|U_k\|_2}
=rac{\|\nabla\psi\|_2}{\|\psi\|_2}.
}
\]

Thus neither Campanato nor shell derivative-frequency escalates with age.

By choosing a sufficiently low-frequency annular template, the fixed ratio can be placed inside any admissible non-H threshold above the geometric localization floor.

## 8. Exact snapshot decoupling from the core

Let

\[
\Omega_k=\nabla\times U_k.
\]

Because `U_k` is smooth, compactly supported and divergence-free, whole-space Biot--Savart recovers it exactly:

\[
\boxed{
\nabla\times(-\Delta)^{-1}\Omega_k=U_k.
}
\]

Hence the velocity and strain generated by `Omega_k` vanish identically outside the support of `U_k`.

In particular, every sufficiently remote shell has **exactly zero snapshot velocity/strain transmission** to a fixed core ball.

This is an idealized saturation of the Campanato commutator result: a remote derivative/enstrophy tower can be completely passive with respect to the core.

## 9. Add a compact nonzero core

Let `U_core` be any fixed smooth compactly supported divergence-free field near the origin and set

\[
U=U_{core}+U_{tail}.
\]

Then simultaneously:

\[
\boxed{
\begin{aligned}
&U\in L^{3,\infty},\qquad U\notin L^3,\\
&U\in L^p\quad\forall p>3,\\
&\nabla U\in L^2,\\
&\sup_k\mathfrak C_k<\infty,\\
&\sup_k\Gamma_k<\infty,\\
&\int_{|Y|<R}|U|^3\asymp\log R,\\
&\text{remote shell transmission to the core can vanish.}
\end{aligned}
}
\]

Thus all principal **static** W1 endpoint constraints are mutually compatible.

## 10. Linear Leray interpretation

Under the passive linear Leray evolution, each critical shell is simply carried outward in log radius and its `L3` mass is unchanged, whereas its `Lp`, `p>3`, mass decays by the factor

\[
e^{-(p-3)\Delta s/2}.
\]

Therefore a shell train of this type is also dynamically natural for the *linear* self-similar drift.

The nonlinear, pressure, and viscous residual of one far critical shell is lower order in its radius, schematically `O(R_k^-3)` in pointwise scaling, consistent with the existing passive-tail decoupling calculations.

This does not make the superposition an exact nonlinear Navier--Stokes/Leray solution.
