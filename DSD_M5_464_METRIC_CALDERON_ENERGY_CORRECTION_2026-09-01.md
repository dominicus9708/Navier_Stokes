# DSD M5-464 — Uniform metric Calderon energy-correction estimate

Date: 2026-09-01

Status: **THE ENERGY-CLASS CORRECTION USED IN LARGE CRITICAL-DATA CALDERON SPLITTINGS EXTENDS TO THE UNIFORMLY ELLIPTIC METRIC SYSTEM / THE NATURAL ENERGY `int U.CU` IS COERCIVE, `C'` IS ONLY A BOUNDED ZERO-ORDER GRONWALL TERM, AND THE INTERACTION WITH A SUBCRITICAL STRONG COMPONENT HAS THE STANDARD ABSORBABLE FORM / THIS PROVIDES THE MAIN A PRIORI BOUND NEEDED FOR A METRIC WEAK-`L3` COMPACTNESS THEORY / GLOBAL REGULARITY REMAINS UNPROVED.**

Use the pulled-back velocity equation in the form

\[
\partial_t w+(w\cdot\nabla)w+H(t)w
=-G(t)\nabla p+\nabla\cdot(G(t)\nabla w),
\]

with

\[
H=C^{-1}C',
\qquad
C=G^{-1},
\qquad
\nabla\cdot w=0.
\]

Assume a common metric class

\[
\kappa^{-1}I\le C,G\le\kappa I,
\qquad
\|C'\|\le M_C.
\]

Split

\[
w=V+U,
\]

where `V` is a strong metric mild solution generated by the better part of a Calderon decomposition and `U` is the energy correction.

Subtracting the equation for `V`,

\[
\partial_tU
+(V\cdot\nabla)U
+(U\cdot\nabla)V
+(U\cdot\nabla)U
+HU
=-G\nabla p_U
+\nabla\cdot(G\nabla U).
\]

Define the metric kinetic energy

\[
\boxed{
E_U(t):=\frac12\int U\cdot C(t)U\,dx.
}
\]

Because `C` is spatially constant and `div U=div V=0`, the pure transport and pure `U` nonlinear terms cancel in this energy. Moreover

\[
\int CU\cdot G\nabla p_U
=
\int U\cdot\nabla p_U
=0.
\]

The diffusion term is

\[
\mathcal D_U
:=
\int G_{ij}(\partial_iU)^TC(\partial_jU)dx
\ge c_\kappa\|\nabla U\|_2^2.
\]

The time-dependent metric contributes only

\[
\left|\frac12\int U\cdot C'U\right|
\le C(M_C,\kappa)E_U.
\]

The remaining nonlinear interaction is the `U dot grad V` term. Since `C` is constant in space, integrate by parts and use Holder with `V in L^{2p}`, `p>3`:

\[
|I_{UV}|
\le C_\kappa
\|V\|_{2p}
\|U\|_{\frac{2p}{p-1}}
\|\nabla U\|_2.
\]

Gagliardo--Nirenberg gives

\[
\|U\|_{\frac{2p}{p-1}}
\le
C
\|U\|_2^{1-\frac{3}{2p}}
\|\nabla U\|_2^{\frac{3}{2p}}.
\]

Therefore Young's inequality yields, for every small `epsilon>0`,

\[
\boxed{
|I_{UV}|
\le
\varepsilon\|\nabla U\|_2^2
+C_{\varepsilon,\kappa,p}
\|V\|_{2p}^{\frac{4p}{2p-3}}
\|U\|_2^2.
}
\]

Hence

\[
\boxed{
\frac d{dt}E_U
+c_\kappa\|\nabla U\|_2^2
\le
C_{\kappa,p}
\left(
M_C+
\|V\|_{2p}^{\frac{4p}{2p-3}}
\right)E_U.
}
\]

If `V` is bounded in `L_t^infinity L_x^{2p}` on a finite interval, Gronwall gives

\[
\boxed{
\|U\|_{L_t^\infty L_x^2}
+\|\nabla U\|_{L_{t,x}^2}
\le
C
}
\]

with constants uniform over coefficient histories in the same compact metric class.

Thus the main energy estimate underlying the standard weak-`L^{3,infinity}` Calderon construction survives coefficient variation.
