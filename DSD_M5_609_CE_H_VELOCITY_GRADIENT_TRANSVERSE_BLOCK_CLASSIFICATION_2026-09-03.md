## 2. Antisymmetric part

For incompressible velocity,

\[
\nabla U=\Sigma+\Omega,
\]

where the antisymmetric part is generated by vorticity.

In the frame with vorticity along the first axis,

\[
\Omega=
\frac12
\begin{pmatrix}
0&0&0\\
0&0&-\rho\\
0&\rho&0
\end{pmatrix}

up to the harmless orientation convention of `(e2,e3)`.

Therefore

\[
\boxed{
\nabla U=
\begin{pmatrix}
\sigma&0&0\\
0&-\sigma/2+\delta&-\rho/2\\
0&\rho/2&-\sigma/2-\delta
\end{pmatrix}.
}
\]

The vorticity direction is a right and left eigenvector of `nabla U` with eigenvalue `sigma`.

## 3. Transverse block determinant

Define

\[

\begin{pmatrix}
-\sigma/2+\delta&-\rho/2\\
\rho/2&-\sigma/2-\delta
\end{pmatrix}.

Its trace is

\[
\operatorname{tr}A_\perp=-\sigma.

\[
\boxed{

:=\det A_\perp
=
\frac{\sigma^2+\rho^2}{4}-\delta^2.

\]

Hence

\[
\det(\nabla U)=\sigma D_\perp.

## 5. Transverse spectral classification

The two eigenvalues of `A_perp` satisfy

\[
\lambda^2+\sigma\lambda+D_\perp=0.
\]

Their discriminant is

\[
\boxed{
\Delta_\perp
=\sigma^2-4D_\perp
=4\delta^2-\rho^2.
}
\]

Therefore:

### Swirling/complex branch

If

\[
4\delta^2<\rho^2,
\]

### Real transverse branch

If

\[
4\delta^2\ge\rho^2,

### Strong hyperbolic branch

If

\[
D_\perp<0,

\[
\boxed{

}
\]
