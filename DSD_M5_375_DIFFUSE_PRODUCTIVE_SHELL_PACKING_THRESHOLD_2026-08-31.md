# DSD M5-375 — Diffuse productive-shell packing threshold

Date: 2026-08-31

Status: **A GENUINELY DIFFUSE CO-CENTERED PRODUCTIVE ANGULAR SOURCE HAS AN EXPONENTIALLY GROWING WEIGHTED-SHELL ENSTROPHY COST / IF NO SHELL CARRIES MORE THAN AN `epsilon` FRACTION OF THE PRODUCTIVE SOURCE, THE MINIMUM COST IS `>= c A^2 R_*^3 8^{c/epsilon}` / ON FIRST-HITTING STAGES WITH THE EXISTING NORMALIZED-TIME CEILING THIS AMPLIFIES THE DISSIPATION TAX TO `~ nu^2 r_j 8^{c/epsilon_j}` / SUFFICIENTLY FAST LINEAR GROWTH OF EFFECTIVE PRODUCTIVE-SHELL MULTIPLICITY IS EXCLUDED / SLOW DIFFUSE SPREAD REMAINS OPEN / GLOBAL REGULARITY UNPROVED.**

## 1. Purpose

The audit-corrected M5-374 established the co-centered shell ledger

\[
\sum_{k\ge0}R_k^3a_k^2
\lesssim
\|\omega(t)\|_2^2,
\]

where

\[
a_k=\gamma_k^{\rm prod}(x,t)\ge0
\]

are productive signed shell contributions at one common center and

\[
R_k=2^kR_*.
\]

For a fixed total productive amplitude

\[
A:=\sum_{k\ge0}a_k,
\]

the previous checkpoint left open whether spreading `A` over many shells forces more energy than concentrating it on a few shells.

The answer has two parts.

1. Without a diffuseness condition, no growing scale-count tax exists.
2. If every shell is forced to carry at most an `epsilon` fraction of `A`, the weighted cost grows exponentially in `1/epsilon`.

This is the quantitative packing threshold of the present note.

## 2. Unconstrained optimization: scale count alone does not cost more

Consider

\[
Q[a]
:=
\sum_{k=0}^\infty R_k^3a_k^2
=
R_*^3\sum_{k=0}^\infty8^ka_k^2
\]

subject to

\[
a_k\ge0,
\qquad
\sum_{k=0}^\infty a_k=A.
\]

Weighted Cauchy--Schwarz gives

\[
A^2
\le
Q[a]
\sum_{k=0}^\infty R_k^{-3}.
\]

Since

\[
\sum_{k=0}^\infty R_k^{-3}
=R_*^{-3}\sum_{k=0}^\infty8^{-k}
=\frac{8}{7}R_*^{-3},
\]

we obtain the sharp ideal-dyadic lower bound

\[
\boxed{
Q[a]
\ge
\frac78A^2R_*^3.
}
\]

Equality in the abstract sequence optimization is attained by

\[
\boxed{
a_k=\frac78A\,8^{-k}.}
\]

Thus an infinite number of outward shells can participate at only order-one extra cost if their productive amplitudes decay geometrically.

This closes the naive claim

\[
\text{more active shells}\Longrightarrow\text{larger energy cost}.
\]

Shell count alone is not enough.

## 3. The optimizer is strongly non-diffuse

The unconstrained optimizer has

\[
\frac{a_0}{A}=\frac78.
\]

Hence the cheap infinite-shell configuration is dominated by its smallest retained shell.

This suggests using the actual multiscale-spread condition from M5-362: no individual shell carries a fixed fraction of the productive source.

Quantify this by assuming

\[
\boxed{
0\le a_k\le\varepsilon A
\qquad\text{for all }k,
}
\]

with

\[
0<\varepsilon<\frac12.
\]

The smaller `epsilon` is, the more genuinely diffuse the scale distribution is.

Define the crude effective multiplicity

\[
\boxed{
N_{\rm eff}:=\frac1\varepsilon.
}
\]

At least order `N_eff` shells are then needed to carry the total productive amplitude.

## 4. Tail-mass lemma under the diffuse cap

Choose

\[
\boxed{
m:=\left\lfloor\frac1{2\varepsilon}\right\rfloor.}
\]

The first `m` shells can carry at most

\[
\sum_{k=0}^{m-1}a_k
\le
m\varepsilon A
\le
\frac A2.
\]

Therefore at least half of the productive amplitude must lie in the remote tail:

\[
\boxed{
\sum_{k\ge m}a_k\ge\frac A2.
}
\]

This is purely combinatorial and is the key gain from the no-dominant-shell condition.

## 5. Exponential weighted-cost lower bound

Apply weighted Cauchy--Schwarz only on the tail `k>=m`:

\[
\left(\sum_{k\ge m}a_k\right)^2
\le
\left(\sum_{k\ge m}R_k^3a_k^2\right)
\left(\sum_{k\ge m}R_k^{-3}\right).
\]

Now

\[
\sum_{k\ge m}R_k^{-3}
=
R_*^{-3}\frac{8^{-m}}{1-8^{-1}}.
\]

Using the half-mass lemma gives

\[
\frac{A^2}{4}
\le
Q[a]
R_*^{-3}\frac{8^{-m}}{1-8^{-1}}.
\]

Hence

\[
\boxed{
Q[a]
\ge
\frac7{32}A^2R_*^3\,8^m.
}
\]

Since

\[
m\ge\frac1{2\varepsilon}-1,
\]

we obtain, up to a universal constant,

\[
\boxed{
Q[a]
\gtrsim
A^2R_*^3
8^{1/(2\varepsilon)}.
}
\]

Equivalently,

\[
\boxed{
Q[a]
\gtrsim
A^2R_*^3
8^{N_{\rm eff}/2}.
}
\]

This is the main packing estimate.

## 6. Consequence for physical enstrophy

The co-centered shell ledger of M5-374 gives

\[
Q[a]
\lesssim
\|\omega(t)\|_2^2.
\]

Therefore a diffuse productive source at one center and time satisfies

\[
\boxed{
\|\omega(t)\|_2^2
\gtrsim
A(t)^2R_*^3
8^{1/(2\varepsilon)}.
}
\]

This is an instantaneous global-enstrophy lower bound generated by the productive angular network.

For `R_*=c_0r_j`, it is natural to compare `A` with the first-hitting stretching scale `W_j~nu/r_j^2`.

At an order-one normalized productive event,

\[
A\gtrsim W_j,
\]

so schematically

\[
\boxed{
\|\omega(t)\|_2^2
\gtrsim
\frac{\nu^2}{r_j}
8^{1/(2\varepsilon)}.
}
\]

The dimensionless critical enstrophy ratio therefore grows at least exponentially with effective shell multiplicity.

## 7. Time-action version

An isolated instantaneous lower bound is not enough because the Leray budget is integrated in time.

Let `E_j` be a subset of a first-hitting stage on which the non-sub-natural productive action is carried and suppose:

1. the co-centered productive amplitude is `epsilon_j`-diffuse at the centers relevant to `P_j^{>=}(t)`;
2. `E_j` carries a fixed fraction `sigma>0` of the required first-hitting action:

\[
\int_{E_j}P_j^{\ge}(t)dt
\ge
\sigma\log q;
\]

3. the existing normalized stage ceiling applies:

\[
\Theta_j=W_j|I_j|\le L_*.
\]

From Section 5 and the M5-374 shell ledger,

\[
P_j^{\ge}(t)
\lesssim
r_j^{-3/2}
8^{-m_j/2}
\|\omega(t)\|_2,
\]

where

\[
m_j=\left\lfloor\frac1{2\varepsilon_j}\right\rfloor.
\]

Integrating over `E_j` and using Cauchy--Schwarz gives

\[
(\sigma\log q)^2
\lesssim
r_j^{-3}8^{-m_j}|E_j|
\int_{E_j}\|\omega(t)\|_2^2dt.
\]

Since

\[
|E_j|\le|I_j|
\le
\frac{L_*r_j^2}{\nu},
\]

we obtain

\[
\boxed{
\nu\int_{E_j}\|\omega(t)\|_2^2dt
\gtrsim_{q,\sigma,c_0,L_*}
\nu^2r_j\,8^{m_j}.
}
\]

Thus, up to constants,

\[
\boxed{
\nu\int_{E_j}\|\omega|_2^2dt
\gtrsim
\nu^2r_j
8^{1/(2\varepsilon_j)}.
}
\]

This is the **diffuse productive-shell stage tax**.

## 8. Global finite-energy restriction

The first-hitting stages are time-disjoint and the Leray--Hopf budget is finite. Therefore any infinite sequence of stages satisfying the diffuse-action assumptions must obey

\[
\boxed{
\sum_j
r_j\,8^{m_j}<\infty.
}
\]

For geometric first-hitting levels

\[
W_j=q^jW_0,
\]

we have

\[
r_j\asymp q^{-j/2}.
\]

Hence the necessary series condition becomes

\[
\boxed{
\sum_j
q^{-j/2}
8^{m_j}<\infty.
}
\]

This turns diffuse scale multiplicity into a quantitative growth restriction.

## 9. Linear effective-multiplicity threshold

Since

\[
m_j\sim\frac{N_{{\rm eff},j}}2,
\]

suppose

\[
N_{{\rm eff},j}
\ge
\alpha j
\]

for all sufficiently large `j` on a fixed-action diffuse subsequence.

Then the stage tax behaves at least like

\[
q^{-j/2}8^{\alpha j/2}
=
\exp\left[
\frac j2(\alpha\log8-\log q)
\right].
\]

Therefore, in the ideal dyadic constants of this estimate,

\[
\boxed{
\alpha>\frac{\log q}{\log8}
\quad\Longrightarrow\quad
\text{the diffuse branch exhausts the finite dissipation budget.}
}
\]

For the common bookkeeping choice `q=2`, the ideal threshold is

\[
\boxed{
\alpha>\frac13.
}
\]

The numerical constant is not promoted to a theorem invariant; smooth shell partitions and retained-action fractions modify prefactors. The robust statement is that **sufficiently fast linear growth of effective productive-shell multiplicity is impossible on the bounded-normalized-time branch.**

## 10. What remains if `epsilon_j -> 0` slowly

The conclusion does not exclude every sequence with

\[
\varepsilon_j\to0.
\]

For example, if

\[
N_{{\rm eff},j}=o(j),
\]

then

\[
8^{N_{{\rm eff},j}/2}
\]

may remain subexponential in `j`, while

\[
r_j\sim q^{-j/2}
\]

decays exponentially.

The resulting dissipation taxes can still be summable.

Therefore the surviving multiscale spread is now sharply characterized as a **slow-diffusion-in-scale branch** rather than an unrestricted many-scale branch.

## 11. Dominant-shell alternative reconnects to the old tree

If `epsilon_j` does not tend to zero, there exists `epsilon_0>0` and infinitely many stages with a shell carrying at least an `epsilon_0` fraction of the productive source.

Let its normalized index be `k_j`.

Then M5-362's source-scale trichotomy applies:

\[
\boxed{
\begin{array}{rcl}
k_j\to-\infty
&\Longrightarrow&
H_{\rm der/occ}\ \text{(sub-natural)},\\
|k_j|=O(1)
&\Longrightarrow&
P_{\rm angular}/T_{\rm partner}\ \text{(natural)},\\
k_j\to+\infty
&\Longrightarrow&
T_{\rm remote}/H_{\rm ambient}\ \text{(remote)}.
\end{array}
}
\]

Thus the truly new survivor is only

\[
\boxed{
\varepsilon_j\to0
\quad\text{with effective multiplicity growing too slowly to violate the stage budget.}
}
\]

## 12. DSD analysis interpretation

Scale multiplicity must not be represented by the raw number of shells with nonzero contribution.

The correct descriptor is amplitude-sensitive.

One minimal descriptor is

\[
\boxed{
\varepsilon
=
\frac{\max_ka_k}{\sum_ka_k},
\qquad
N_{\rm eff}=\varepsilon^{-1}.
}
\]

This distinguishes:

- one dominant productive shell plus harmless tails;
- genuinely diffuse productive scale spread;
- an arbitrarily large number of negligible shells that carry essentially no action.

The first version would overcount the latter two if it used shell count alone.

## 13. Axis-property interpretation

The quantity `a_k` is a **signed productive longitudinal-stretching amplitude**, not an unsigned direction-roughness amplitude.

Consequently the exponential packing tax applies only after the axis geometry has been projected through the actual Biot--Savart stretching sign.

This prevents harmless angular complexity from being charged as if it were dynamically productive.

## 14. Audit firewalls

### Firewall A: center must remain common

The weighted shell packing estimate is valid only for the shell vector at one common spatial center before taking the supremum.

### Firewall B: diffuseness must carry action in time

An instantaneous diffuse event of measure zero cannot be charged to the time-integrated Leray budget. A fixed fraction of first-hitting productive action must pass through the diffuse regime.

### Firewall C: normalized-time ceiling is branch-dependent input

The amplified stage tax uses the previously established finite normalized-stage ceiling. If that ceiling is lost, temporal turnover/concentration is a separate survivor.

### Firewall D: slow diffuseness is not excluded

`epsilon_j -> 0` alone is insufficient. Its rate relative to the geometric first-hitting index matters.

## 16. Audit verdict

### PROVED

- unconstrained weighted-shell minimizer has order-one dominant smallest shell;
- no-dominant-shell cap forces half of the action beyond `~1/(2 epsilon)` shells;
- diffuse weighted cost `Q >= c A^2 R_*^3 8^{1/(2 epsilon)}`;
- under fixed-action time persistence and normalized-stage ceiling, diffuse stage dissipation tax `>= c nu^2 r_j 8^{1/(2 epsilon_j)}`;
- sufficiently fast linear effective-multiplicity growth contradicts finite Leray dissipation.

### CLOSED / REDUCED

- raw shell count is not a valid packing cost;
- fast diffuse productive scale proliferation is excluded on the bounded-normalized-time non-sub-natural branch;
- non-diffuse productive scale spread reconnects to the existing dominant-shell H/P/T trichotomy.
