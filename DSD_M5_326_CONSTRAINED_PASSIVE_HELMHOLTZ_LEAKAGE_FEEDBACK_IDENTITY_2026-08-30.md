## 2. Passive trajectory and Helmholtz split

Let

\[
z(t)=S(t,s)q,
\qquad \nabla\cdot q=0,
\]

solve

\[
z_t+(u\cdot\nabla)z=\nu\Delta z.
\]

Write

\[
\boxed{z=v+g,\qquad v=\mathbb Pz,\qquad g=\mathbb Qz.}
\]

On `R^3`, `P,Q` commute with the Laplacian.

Hence

\[
\boxed{
v_t
=\nu\Delta v
-\mathbb P[(u\cdot\nabla)v]
-\mathbb P[(u\cdot\nabla)g],
}
\]

and

\[
\boxed{
g_t
=\nu\Delta g
-\mathbb Q[(u\cdot\nabla)v]
-\mathbb Q[(u\cdot\nabla)g].
}
\]

Initially

\[
g(s)=0.
\]

Thus the passive trajectory begins entirely in the solenoidal channel, but advection can create a gradient component.

## 3. Constrained Oseen trajectory

Let

\[
h(t)=U(t,s)q
\]

solve

\[
h_t
=\nu\Delta h
-\mathbb P[(u\cdot\nabla)h],
\qquad h(s)=q.
\]

Define the solenoidal difference

\[
\delta=h-v.
\]

Subtracting the equations gives the exact identity

\[
\boxed{
\delta_t
=\nu\Delta\delta
-\mathbb P[(u\cdot\nabla)\delta]
+\mathbb P[(u\cdot\nabla)g],
\qquad
\delta(s)=0.
}
\]

Thus constrained/passive separation is caused only by feedback from the gradient channel `g` into the solenoidal channel.

## 4. Gradient-channel feedback is a velocity-gradient interaction

Since `g=Qz` is a gradient field, write locally/globally in the homogeneous sense

\[
g=\nabla\phi.
\]

Then

\[
(u\cdot\nabla)g
=\nabla(u\cdot g)-(\nabla u)^Tg.
\]

The first term is a pure gradient and is annihilated by `P`. Therefore

\[
\boxed{
\mathbb P[(u\cdot\nabla)g]
=-\mathbb P[(\nabla u)^Tg].
}
\]

Consequently

\[
\boxed{
\delta_t
=\nu\Delta\delta
-\mathbb P[(u\cdot\nabla)\delta]
-\mathbb P[(\nabla u)^Tg].
}
\]

This is the exact leakage-feedback identity.
