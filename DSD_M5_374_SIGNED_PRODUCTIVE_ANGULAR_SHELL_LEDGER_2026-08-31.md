## 1. Purpose and audit correction

M5-362 proved that first-hitting vorticity growth requires a nontrivial angular Biot--Savart source, but used the absolute majorant

\[
\int \frac{|\omega(x+y)|\sin\theta(x,x+y)}{|y|^3}\,dy.
\]

M5-373 showed that a generic linear scale sum cannot be closed merely from a quadratic frequency-energy ledger.

The present note keeps the **sign of the actual longitudinal stretching contribution** and uses the fact that dyadic physical source shells about one fixed center are pairwise disjoint.

The first version of this checkpoint contained an audit error: from a fixed-center estimate it passed to

\[
\sum_k\|\gamma_k^+\|_\infty.
\]

That is not legitimate because a different spatial center may realize the supremum for each `k`.

The correct order is

\[
\boxed{
\text{sum the productive shells at one common center}
\quad\longrightarrow\quad
\text{then take one spatial supremum}.
}
\]

All statements below use this corrected order.

## 2. Signed dyadic shell decomposition

At a point with nonzero vorticity, write

\[
\xi(x,t)=\frac{\omega(x,t)}{|\omega(x,t)|},
\qquad
\gamma(x,t)=\xi(x,t)^TS[\omega](x,t)\xi(x,t).
\]

Use a smooth radial dyadic partition on `R^3 \ {0}` and write

\[
S[\omega]=\sum_k S_k[\omega],
\]

where `S_k` is generated by source distances

\[
R_k\lesssim |y|\lesssim 2R_k.
\]

Define the signed shell contribution

\[
\boxed{
\gamma_k(x,t)
:=
\xi(x,t)^TS_k[\omega](x,t)\xi(x,t).
}
\]

Then

\[
\boxed{
\gamma(x,t)=\sum_k\gamma_k(x,t)
}
\]

in the usual principal-value/distributional sense.

Define

\[
\gamma_k^{\rm prod}(x,t):=[\gamma_k(x,t)]_+.
\]

This retains only shell contributions with the correct sign for longitudinal amplification.

## 3. Co-centered productive source

For a set of shell indices `K`, define at one common center

\[
\boxed{
\mathcal P_K(x,t)
:=
\sum_{k\in K}\gamma_k^{\rm prod}(x,t).
}
\]

Then define the corresponding spatial observable only after forming the sum:

\[
\boxed{
P_K(t)
:=
\sup_{x:\,\omega(x,t)\ne0}\mathcal P_K(x,t).
}
\]

For the full shell family,

\[
[\gamma(x,t)]_+
=\left[\sum_k\gamma_k(x,t)\right]_+
\le
\sum_k[\gamma_k(x,t)]_+
=\mathcal P_{\mathbb Z}(x,t).
\]

Therefore

\[
\boxed{
\|\gamma^+(t)\|_\infty
\le
P_{\mathbb Z}(t).
}
\]

M5-340 gives for every geometric first-hitting stage `I_j=[t_j,t_{j+1}]`

\[
\boxed{
\int_{I_j}P_{\mathbb Z}(t)dt
\ge
\log q.
}
\]

This is the rigorous productive shell action required below.

No measurable maximizing trajectory is needed.

## 4. One-shell `L2` source estimate

For a shell at radius `R`, the angular kernel has size at most `C|y|^{-3}`. Hence for every fixed center `x`,

\[
|\gamma_R(x,t)|
\le
C\int_{A_R(x)}\frac{|\omega(z,t)|}{|z-x|^3}dz.
\]

Cauchy--Schwarz gives

\[
|\gamma_R(x,t)|
\lesssim
R^{-3/2}
\left(
\int_{A_R(x)}|\omega(z,t)|^2dz
\right)^{1/2}.
\]

Therefore

\[
\boxed{
R^3|\gamma_R^{\rm prod}(x,t)|^2
\lesssim
\int_{A_R(x)}|\omega(z,t)|^2dz.
}
\]

## 5. Correct disjoint-shell square ledger

For one fixed `x` and `t`, the shell regions `A_{R_k}(x)` have bounded overlap. Hence

\[
\boxed{
\sum_kR_k^3|\gamma_k^{\rm prod}(x,t)|^2
\lesssim
\|\omega(t)\|_2^2.
}
\]

This is the genuine additive shell ledger.

### Firewall

It does **not** imply

\[
\sum_kR_k^3\|\gamma_k^{\rm prod}(t)\|_\infty^2
\lesssim
\|\omega(t)\|_2^2.
\]

The latter would allow different maximizing centers for different shells and is not derived.

This is the central DSD correction.

## 6. Co-centered natural-and-larger `ell1` bound

Fix a minimum retained source radius `R_*` and let

\[
K_{\ge R_*}:=\{k:R_k\ge R_*\}.
\]

At each fixed center, weighted Cauchy--Schwarz and Section 5 give

\[
\begin{aligned}
\mathcal P_{\ge R_*}(x,t)
&=
\sum_{R_k\ge R_*}\gamma_k^{\rm prod}(x,t)\\
&\le
\left(
\sum_{R_k\ge R_*}R_k^3|\gamma_k^{\rm prod}(x,t)|^2
\right)^{1/2}
\left(
\sum_{R_k\ge R_*}R_k^{-3}
\right)^{1/2}\\
&\lesssim
R_*^{-3/2}\|\omega(t)\|_2.
\end{aligned}
\]

Now, and only now, take the supremum over `x`:

\[
\boxed{
P_{\ge R_*}(t)
\lesssim
R_*^{-3/2}\|\omega(t)\|_2.
}
\]

This is the corrected natural-and-larger source estimate.

## 7. Formation split at the natural scale

For stage `j`, let

\[
r_j=\sqrt{\frac{\nu}{W(t_j)}}
\]

and fix `c0>0`.

Define

\[
P_j^{<}(t)
:=
\sup_x
\sum_{R_k<c_0r_j}\gamma_k^{\rm prod}(x,t),
\]

and

\[
P_j^{\ge}(t)
:=
\sup_x
\sum_{R_k\ge c_0r_j}\gamma_k^{\rm prod}(x,t).
\]

Since

\[
P_{\mathbb Z}(t)
\le
P_j^{<}(t)+P_j^{\ge}(t),
\]

first-hitting growth implies

\[
\int_{I_j}P_j^{<}(t)dt
+
\int_{I_j}P_j^{\ge}(t)dt
\ge
\log q.
\]

Therefore every stage obeys the exact dichotomy

\[
\boxed{
\int_{I_j}P_j^{<}dt\ge\frac12\log q
\quad\lor\quad
\int_{I_j}P_j^{\ge}dt\ge\frac12\log q.
}
\]

The first branch is the sub-natural angular/derivative route already sent to `H_der/occ` by M5-362 and M5-372.

The second is the non-sub-natural productive source branch.

## 8. Correct first-hitting dissipation tax

On the second branch, Section 6 with `R_*=c0 r_j` gives

\[
P_j^{\ge}(t)
\lesssim
r_j^{-3/2}\|\omega(t)\|_2.
\]

Thus

\[
\log q
\lesssim
r_j^{-3/2}
\int_{I_j}\|\omega(t)\|_2dt.
\]

Cauchy--Schwarz in time gives

\[
(\log q)^2
\lesssim
r_j^{-3}|I_j|
\int_{I_j}\|\omega(t)\|_2^2dt.
\]

Define

\[
\boxed{
\Theta_j
:=
W(t_j)|I_j|

Then

\[
\boxed{

\gtrsim_{q,c_0}
\frac{\nu^2r_j}{\Theta_j}.

\]

Thus the stage tax survives the audit correction.

What changed is the logical route: it comes from a **co-centered shell sum followed by one supremum**, not from a sum of shellwise `L-infinity` norms.
