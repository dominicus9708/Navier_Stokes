## 1. Goal

Earlier remote-H estimates used the direct vorticity `L2` Biot--Savart bound and therefore required a vorticity-tightness input to make the transmitted core strain small at large radius.

The present note uses relative velocity instead. The point is that a compact divergence-free velocity localization supported in a remote annulus produces no velocity or strain at the core; the only transmitted field comes from the cutoff/Bogovskii commutator. This yields an additional inverse power of the annular radius.

## 2. One annulus

Let

\[
A_R=\{R<|y|<2R\}
\]

and choose a fixed-shape enlarged annulus `A_R^+` with a cutoff `chi_R` satisfying

\[
|\nabla\chi_R|\lesssim R^{-1}.
\]

Let `c_R` be the annular mean (or the weighted mean used in the relative-variance ledger) and write

\[
v_R:=U-c_R.
\]

Let `b_R` be the Bogovskii correction solving

\[
\nabla\cdot b_R=\nabla\chi_R\cdot v_R
\]

inside the annular buffer, with zero trace there. Define

\[
f_R:=\chi_Rv_R-b_R.
\]

Then

\[
\nabla\cdot f_R=0,
\qquad
\operatorname{supp}f_R\subset A_R^+.
\]

The scaled Bogovskii estimate gives

\[
\|\nabla b_R\|_2
\lesssim
\|\nabla\chi_R\cdot v_R\|_2
\lesssim R^{-1}\|v_R\|_{L^2(A_R^+)}.
\]

## 3. Exact vorticity decomposition

Because constants have zero curl,

\[
\nabla\times(\chi_Rv_R)
=
\chi_R\Omega+\nabla\chi_R\times v_R.
\]

Therefore

\[
\boxed{
\chi_R\Omega
=
\nabla\times f_R
-
q_R,
}
\]

where

\[
q_R
:=
\nabla\chi_R\times v_R
-
\nabla\times b_R.
\]

The preceding estimates imply

\[
\boxed{
\|q_R\|_2
\lesssim
R^{-1}\|v_R\|_{L^2(A_R^+)}.
}
\]

## 4. Why the compact solenoidal part does not transmit to the core

Let `B` denote the whole-space Biot--Savart map from vorticity to velocity,

\[
B(\omega)=\nabla\times(-\Delta)^{-1}\omega.
\]

For compactly supported divergence-free `f_R`,

\[
B(\nabla\times f_R)=f_R.
\]

Since `f_R` is supported in `A_R^+`, it vanishes on every fixed core ball once `R` is sufficiently large. Hence its velocity and strain at the core are exactly zero.

Thus the core field generated by the localized remote vorticity `chi_R Omega` is entirely the commutator field generated by `q_R`:

\[
\boxed{
\nabla B(\chi_R\Omega)
=-\nabla B(q_R)
\quad\text{on the fixed core.}
}
\]

This is the transmission identity behind the estimate below.

## 5. Pointwise core-strain estimate

For a core point `x` with `|x|<=M` and `R>>M`, the strain kernel obeys

\[
|K_S(x-y)|\lesssim R^{-3}
\qquad(y\in A_R^+).
\]

Therefore

\[
|S_R(x)|
\lesssim
R^{-3}\|q_R\|_1
\lesssim
R^{-3}|A_R^+|^{1/2}\|q_R\|_2.
\]

Since `|A_R^+|^{1/2}\asymp R^{3/2}`,

\[
|S_R(x)|
\lesssim
R^{-3}R^{3/2}R^{-1}
\|v_R\|_{L^2(A_R^+)}.
\]

Hence

\[
\boxed{
\|S_R\|_{L^\infty(B_M)}
\lesssim
R^{-5/2}
\|U-c_R\|_{L^2(A_R^+)}.
}
\]

Define the shell relative-Campanato quantity

\[
\mathfrak C_R
:=
R^{-1}
\|U-c_R\|_{L^2(A_R^+)}^2.
\]

Then

\[
\boxed{
\|S_R\|_{L^\infty(B_M)}
\lesssim
R^{-2}\mathfrak C_R^{1/2}.
}
\]
