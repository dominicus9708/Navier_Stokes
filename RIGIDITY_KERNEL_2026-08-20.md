## 1. Differential characterization of the strain-projection kernel

For a symmetric matrix field `M in L^2`, the symmetric-matrix Helmholtz decomposition gives

\[
\boxed{
\|P_{st}M\|_2^2
=2\|\nabla\times\operatorname{div}(-\Delta)^{-1}M\|_2^2.
}
\]

Therefore

\[
\boxed{
P_{st}M=0
\iff
\nabla\times\operatorname{div}(-\Delta)^{-1}M=0.
}
\]

Equivalently, in Fourier variables for almost every `xi != 0`,

\[
\boxed{
\xi\times(\widehat M(\xi)\,\xi)=0.
}
\]

Thus `M hat(xi) xi` is parallel to `xi`, and in distributional form

\[
\boxed{
\nabla\times\operatorname{div}M=0,
}
\]

or equivalently `div M` is a gradient field (in the appropriate homogeneous distributional class).

Applied to

\[
Q=\frac13S^2+\frac14\omega\otimes\omega,
\]

the exact `G_Q` condition is therefore a nonlinear static stress-balance constraint

\[
\boxed{
\nabla\times\operatorname{div}Q=0.
}
\]

## 2. Derivative orthogonality forced by the kernel

Assume sufficient regularity, e.g. `S in H^2`, generated by a divergence-free velocity field. Then `-Delta S` is again in the strain constraint space. Hence

\[
\langle-\Delta S,Q\rangle
=
\langle-\Delta S,P_{st}Q\rangle.
\]

The strain-vorticity identity

\[
\boxed{
\langle-\Delta S,\omega\otimes\omega\rangle=0
}
\]

therefore yields

\[
\boxed{
\frac13\langle-\Delta S,S^2\rangle
=
\langle-\Delta S,P_{st}Q\rangle.
}
\]

Consequently

\[
\boxed{
|\langle-\Delta S,S^2\rangle|
\le
3\|\Delta S\|_2\,\|P_{st}Q\|_2.
}
\]

In particular, the exact projection-kernel condition forces

\[
\boxed{
P_{st}Q=0
\Longrightarrow
\langle-\Delta S,S^2\rangle=0.
}
\]

This is an additional derivative constraint absent from the bare strain-space/max-mid question.

## 3. Exact derivative expansion

Integration by parts gives

\[
\begin{aligned}
\langle-\Delta S,S^2\rangle
&=\sum_a\int \partial_aS:\partial_a(S^2)\,dx\\
&=2\sum_a\int\operatorname{tr}\left(S(\partial_aS)^2\right)dx.
\end{aligned}
\]

Thus

\[
\boxed{
\langle-\Delta S,S^2\rangle
=2\sum_a\int\operatorname{tr}\left(S(\partial_aS)^2\right)dx.
}
\]

In an instantaneous eigenframe `S=R Lambda R^T`, let

\[
\Omega_a=R^T\partial_aR
\]

be the skew frame connection. Then

\[
(R^T\partial_aSR)_{ii}=\partial_a\lambda_i,
\]

\[
(R^T\partial_aSR)_{ij}
=(\lambda_j-\lambda_i)(\Omega_a)_{ij}.
\]

For trace-free `lambda_1+lambda_2+lambda_3=0`,

\[
\boxed{
\operatorname{tr}\left(S(\partial_aS)^2\right)
=
\sum_i\lambda_i(\partial_a\lambda_i)^2
-
\sum_{i<j}\lambda_k(\lambda_i-\lambda_j)^2(\Omega_a)_{ij}^2,
}
\]

where `k` is the index complementary to `{i,j}`.

This separates eigenvalue-amplitude variation from eigenframe rotation.

## 4. Exact max-mid kernel rigidity

Consider the fastest cubic/enstrophy-growth eigenvalue shape

\[
\lambda_1=-2m,
\qquad
\lambda_2=\lambda_3=m,
\qquad
m\ge0.
\]

Write it invariantly as

\[
\boxed{
S=m(I-3n\otimes n),
\qquad |n|=1,
}
\]

where `n` is the compressive eigenaxis.

A direct calculation gives, for every spatial derivative,

\[
\operatorname{tr}\left(S(\partial_aS)^2\right)
=-6m(\partial_am)^2
-9m^3|\partial_an|^2.
\]

Therefore

\[
\boxed{
\langle-\Delta S,S^2\rangle
=-12\int m|\nabla m|^2dx
-18\int m^3|\nabla n|^2dx.
}
\]

Both terms are non-positive. Under the exact kernel condition the left side is zero, hence

\[
m|\nabla m|^2=0
\quad\text{a.e.}
\]

and

\[
m^3|\nabla n|^2=0
\quad\text{a.e.}
\]

Moreover

\[
\nabla(m^{3/2})=\frac32m^{1/2}\nabla m=0
\quad\text{a.e.}
\]

so `m^(3/2)` is a.e. constant on `R^3`. Finite energy (`S in L^2`) forces that constant to be zero.

Hence

\[
\boxed{
\begin{gathered}
S=m(I-3n\otimes n),\quad m\ge0,\quad S\in H^2\cap L^2_{st},\\
P_{st}\left(\frac13S^2+\frac14\omega\otimes\omega\right)=0
\end{gathered}
\Longrightarrow
S\equiv0.
}
\]

This does **not** resolve the broader open max-mid strain-space conjecture. It proves rigidity only after imposing the additional full-NS quadratic-stress kernel condition arising from `G_Q*`.

## 5. Quantitative max-mid visibility estimate

For max-mid geometry, combine the exact formula with

\[
|\langle-\Delta S,S^2\rangle|
\le3\|\Delta S\|_2\|P_{st}Q\|_2.
\]

Then

\[
\boxed{
4\int m|\nabla m|^2dx
+6\int m^3|\nabla n|^2dx
\le
\|\Delta S\|_2\|P_{st}Q\|_2.
}
\]

Since

\[
\int m|\nabla m|^2
=\frac49\|\nabla(m^{3/2})\|_2^2,
\]

Sobolev on `R^3` gives

\[
\|m\|_9^3
=\|m^{3/2}\|_6^2
\lesssim
\|\nabla(m^{3/2})\|_2^2.
\]

Therefore

\[
\boxed{
\|m\|_9^3
\lesssim
\|\Delta S\|_2\,\|P_{st}Q\|_2.
}
\]

Equivalently, whenever `Delta S != 0`,

\[
\boxed{
\|P_{st}Q\|_2
\gtrsim
\frac{\|m\|_9^3}{\|\Delta S\|_2}.
}
\]

Thus an occupied max-mid state with controlled second derivatives cannot become projection-invisible.

## 6. Near-max-mid parameterization

Order eigenvalues increasingly and write

\[
\lambda_1=-2m,
\qquad
\lambda_2=m-d,
\qquad
\lambda_3=m+d,
\]

with

\[
m>0,
\qquad
0\le d<m
\]

in the positive-middle-strain region. `d=0` is exact max-mid.

For one spatial derivative, write

\[
a=\partial_am,
\qquad
b=\partial_ad.
\]

The eigenvalue-amplitude part of
`tr(S(partial_a S)^2)` is exactly

\[
\boxed{
-6ma^2+4dab+2mb^2.
}
\]

The only positive-sign eigenframe term is the rotation inside the two-dimensional positive eigenspace:

\[
\boxed{
+8md^2(\Omega_a)_{23}^2.
}
\]

The `12` and `13` frame-rotation terms have non-positive sign and may be dropped when deriving an upper bound.

Assume a near-max-mid pointwise defect bound

\[
0\le d\le\eta m.
\]

Young's inequality gives

\[
4|dab|
\le
ma^2+4\eta^2mb^2.
\]

Hence

\[
\boxed{
\operatorname{tr}(S(\partial_aS)^2)
\le
-5m(\partial_am)^2
+(2+4\eta^2)m(\partial_ad)^2
+8md^2(\Omega_a)_{23}^2.
}
\]

Summing in `a` and using the approximate-kernel derivative estimate yields

\[
\boxed{
\begin{aligned}
10\int m|\nabla m|^2
\le{}&
(4+8\eta^2)\int m|\nabla d|^2\\
&+16\int md^2|\Omega_{23}|^2\\
&+3\|\Delta S\|_2\|P_{st}Q\|_2.
\end{aligned}
}
\]

Therefore Sobolev gives the schematic quantitative alternative

\[
\boxed{
\begin{aligned}
\|m\|_9^3
\lesssim{}&
\int m|\nabla d|^2
+\int md^2|\Omega_{23}|^2\\
&+\|\Delta S\|_2\|P_{st}Q\|_2,
\end{aligned}
}
\]

with constants depending only on the fixed near-max-mid window `eta`.

Interpretation: a nontrivial near-max-mid state cannot simultaneously have

1. small max-mid defect derivative `nabla d`,
2. small in-plane projective/eigenframe reorganization,
3. small higher-derivative scale `Delta S`, and
4. small quadratic-stress projection `P_st Q`.

Hence the fastest self-amplification geometry no longer survives as a clean exact-kernel endpoint.
