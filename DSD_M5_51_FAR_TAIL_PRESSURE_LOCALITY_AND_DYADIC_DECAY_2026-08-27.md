## 2. Pressure-Poisson representation

For the normalized incompressible field `U`,

\[
-\Delta P
=
\partial_i\partial_j(U_iU_j).
\]

Up to a time-dependent pressure gauge,

\[
P
=
\mathcal R_i\mathcal R_j(U_iU_j).
\]

Write the Calderon--Zygmund kernel schematically as

\[
P(y)
=
\operatorname{p.v.}
\int_{\mathbb R^3}
K_{ij}(y-z)U_i(z)U_j(z)\,dz,

where

\[
|K_{ij}(w)|\le C|w|^{-3},
\qquad
|\nabla K_{ij}(w)|\le C|w|^{-4}.
\]

Only the far-field part will be used below, so no principal-value issue occurs there.

## 4. Far-pressure decomposition

Fix a core radius `R_0` and choose

\[
R\ge \max(2R_0,R_*).
\]

For `|y|\le R_0`, define the pressure generated by the remote region `|z|>R`:

\[
P_{>R}(y)
:=
\int_{|z|>R}
K_{ij}(y-z)U_i(z)U_j(z)\,dz.
\]

Since `|y-z|\ge |z|/2`, the tail envelope yields

\[
\begin{aligned}
|P_{>R}(y)|
&\le
CM^2
\int_R^\infty
r^{-3}r^{-2}r^2\,dr\\
&\le
\boxed{CM^2R^{-2}}.
\end{aligned}

Similarly,

\[
\begin{aligned}
|\nabla P_{>R}(y)|
&\le
CM^2
\int_R^\infty
r^{-4}r^{-2}r^2\,dr\\
&\le
\boxed{CM^2R^{-3}}.
\end{aligned}
\]

Thus remote `1/r` velocity ancestry produces only an `R^{-2}` pressure and an `R^{-3}` pressure gradient at a fixed normalized core.

## 5. Gauge-free pressure-flux estimate on a closed core surface

Let `Sigma` be a closed regular surface contained in `B_{R_0}`, bounding a region `Omega`, and let `n` be its outward normal.

Because

\[
\nabla\cdot U=0,
\]

we have

\[
\int_\Sigma U\cdot n\,dS=0.
\]

Hence for any fixed `y_0\in B_{R_0}`,

\[
\int_\Sigma P_{>R}U\cdot n\,dS
=
\int_\Sigma
\bigl(P_{>R}-P_{>R}(y_0)\bigr)
U\cdot n\,dS.
\]

Using the gradient bound,

\[
\operatorname{osc}_{B_{R_0}}P_{>R}
\le
CM^2R_0R^{-3}.
\]

Therefore

\[
\boxed{
\left|
\int_\Sigma P_{>R}U\cdot n\,dS
\right|
\le
CM^2R_0R^{-3}
\int_\Sigma|U\cdot n|\,dS.
}
\]

This estimate is pressure-gauge invariant because the constant part cancels exactly.

Decompose the far field into shells

\[

## 10. What the estimate does not prove

The estimate has no sign.

It does not show that near-shell pressure work is dissipative, irreversible, or monotone from one return to the next.

It also does not prohibit the same finite-neighbor shell architecture from being regenerated at each smaller physical scale by recurrence.

Therefore

\[
\boxed{
\text{pressure locality}
\not\Rightarrow
\text{pressure depletion}.
}
\]

The signed-cocycle gate from M5-50 remains open.
