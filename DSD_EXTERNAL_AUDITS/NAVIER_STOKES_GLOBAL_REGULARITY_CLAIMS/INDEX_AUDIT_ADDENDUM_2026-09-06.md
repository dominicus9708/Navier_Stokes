# DSD External Audit Addendum — 2025–2026 Claimed 3D Navier–Stokes Resolutions

Date: 2026-09-06
Scope: additive status map after the initial registry.

This index is deliberately **version-aware** and **argument-focused**. It does not classify authors as competent/incompetent and does not infer validity from credentials, venue, tone, or software certificates.

Legend:

- `FAIL_ROOT`: a displayed/public root hinge has a direct mathematical/logical failure.
- `CONDITIONAL`: useful implication/framework, but decisive hypothesis remains unproved.
- `SCOPE`: proves/studies a modified/augmented model unless equivalence is shown.
- `OPEN_DEEP`: public summary is insufficient for a final verdict; formula-level audit remains.
- `IMPLEMENTATION_FAIL`: computational artifact does not implement the claimed PDE verification; analytical paper remains separate.

## III. Modified-model claims that should be separated from Clay claims

The following class can contain correct mathematics but is **not** the original problem unless an explicit zero-parameter/equivalence theorem is supplied:

- biharmonic/hyperviscous regularization;
- nonlocal fractal high-frequency damping;
- active phase/pressure feedback controls;
- quantum-force/minimum-force corrections;
- external topological projections;
- arithmetic/modular target-space dynamics without a faithful NSE equivalence theorem.

DSD policy: retain useful modified-model results, but never allow “regularized system is smooth” to silently inherit the label “classical 3D NSE is smooth.”

1. directional/eigen-gap packet + Carleson packing;
