## 1. Why a versioned audit is necessary

The SAPZ program has many public revisions. A fair audit must not treat all versions as one immutable proof.

The decisive question is not whether an early manuscript used strong language, but whether the latest chain actually discharges every hypothesis that earlier versions left open.

## 2. v4.3r1 self-declared status

The public v4.3r1 description makes an unusually explicit distinction:

- criterion-level interface: uniform SAPZ subcriticality implies regularity/continuation;
- necessity: a finite-time singularity forces threshold reach;
- **single Clay-level PDE completion target:** averaged strict-margin input `CT3-(A3)` remains to be proved;
- Route T is presented as a blueprint for reducing that target.

This is strong evidence that, at v4.3r1, the program had **not** yet established unconditional global regularity.

Therefore any earlier version in the same chain that advertised complete unconditional resolution without discharging this target should be marked historically incomplete/superseded.

## 3. v5.3r2A upgrade

## 4. Current DSD hinge list for Route T

The latest unconditional claim stands or falls on the following points:

### H1. Approximate-identity Gate A

The mollified/trace-energy object must identify the declared physical quantity uniformly in the solution class and in the limit `ε→0`.

Potential failure mode:

\[
\text{pointwise/strong identification}
\text{ assumed at a weak solution where concentration is exactly the issue.}
\]

### H2. ε-independent Riccati constants

If

\[
\delta_\varepsilon'
\le a\delta_\varepsilon^2+b\delta_\varepsilon+c
\]

or an equivalent normal form is used, every coefficient and residual bound needed for the threshold must remain uniform as the mollification scale vanishes.

A bound of the form

\[
C(\varepsilon)\to\infty
\]

cannot yield a universal Clay-level threshold.

### H3. CT3 scale persistence / selection

A good scale on each finite horizon must be selected without assuming the subcriticality or compactness that is supposed to be concluded.

The exact quantifier order is critical:

\[
\forall T\ \exists r(T)
\]

is weaker than a uniform-in-scale/horizon gate if the continuation argument requires the latter.

### H4. Route–T positive transport residual

The public summary says Route T extracts a strictly positive transport residual. The proof must establish that the residual is:

- positive with a quantitative constant;
- not canceled by pressure/commutator tails;
- uniform in the vanishing scale;
- not merely a diagnostic of already-smooth solutions;
- compatible with low-amplitude/intermittent concentration.

### H5. Gate B / CKN bridge

The SAPZ strict margin must control an actual CKN epsilon quantity with a fixed bridge constant. Normalization of the SAPZ diagnostic cannot manufacture CKN smallness.

## 6. Positive research value

The SAPZ program has several audit-positive features:

- it explicitly distinguishes criterion from unconditional completion in at least one revision;
- it maintains companion proof modules;
- it isolates a small number of named gates;
- it attempts to track mollifier-independent constants;
- it supplies nonvacuity examples in known small-data regimes.

These make it easier to audit than a proof whose assumptions are unnamed.

## 7. Regression tests for M17

SAPZ's history is directly relevant to the internal M17 chain. We must avoid:

- calling a conditional Gate an unconditional closure;
- losing uniformity when a packet/mollifier scale tends to zero;
- changing `∀T ∃scale` into a growing-lag uniform statement;
- using normalization to cross an external epsilon threshold;
- allowing a named “residual positivity” to hide low-amplitude cancellation.
